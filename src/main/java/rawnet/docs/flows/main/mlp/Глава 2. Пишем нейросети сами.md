# Глава 2. Пишем нейросети сами

В этой главе мы создадим несколько самописных, но вполне рабочих MLP-нейросетей, способных решать простые, но реальные [задачи](tasks/Задачи.md).

Три реализации — три ступени:
- IrisNeuron — нейрон как объект. Максимально «в лоб»: видно каждый шаг backprop. Медленно, но понятно.
- IrisMatrix — те же шаги, но через матрицы. Быстрее, но формулы те же.
- MlpMatrix — универсальная сеть с батчами. Это уже production-подход.

Сначала поймите IrisNeuron — потом смотрите, как то же самое записывается матрицами.
Матрицы — это не «другой алгоритм», а та же математика, записанная компактно.

## Нейросеть где нейрон как объект

Вообще-то весь мир пишет нейросети через матричные вычисления: это быстрее и лучше распараллеливается.
Мы тоже так будем делать, но сначала напишем нейросеть так, будто каждый её нейрон — отдельный объект.

Это учебный пример: он показывает «в лоб» все шаги backpropagation на уровне отдельных нейронов, без матричной алгебры. Когда вы увидите те же шаги в матричной форме, будет понятно, что матрицы — это просто компактная запись того же самого.

Ну или вы можете представить будто у вас есть куча маленьких нейрончиков-вычислителей каждый из которых работает отдельно, и они как раз обмениваются между собой сигналами образуя нейросеть.

Решим [задачу классификации Ирисов](tasks/Задачи.md#задача-классификации-ирисов).

Напишем [нейронную сеть](glava2/code/IrisNeuron.java)
```java
/**
 * Решение задачи классификации ирисов в концепции «нейрон как объект».
 * Каждый нейрон хранит собственные веса, смещение, выход и дельту ошибки.
 *
 * Это учебный пример: он показывает backpropagation «в лоб»,
 * на уровне отдельных нейронов, без матричной алгебры.
 */
public class IrisNeuron {

    static final Random RND = new Random(42);
    static final float LR = 0.01f; // скорость обучения

    static final int IN = 4, HID = 10, OUT = 3;

    /** Один нейрон. */
    static class Neuron {
        final float[] w;  // веса входных связей
        float b;          // смещение
        float z;          // взвешенная сумма (до активации)
        float a;          // выход (после активации)
        float delta;      // δ = dL/dz

        Neuron(int inputSize) {
            w = new float[inputSize];
            b = rnd();
            for (int i = 0; i < inputSize; i++) w[i] = rnd();
        }

        static float rnd() { return RND.nextFloat() * 0.2f - 0.1f; }

        static float sigmoid(float x) {
            return 1f / (1f + (float) Math.exp(-x));
        }

        static float sigmoidDeriv(float a) { return a * (1 - a); }

        /** Прямой проход: z = w·x + b, a = σ(z). */
        float forward(float[] x) {
            z = b;
            for (int i = 0; i < x.length; i++) z += x[i] * w[i];
            return a = sigmoid(z);
        }

        /** Обратный проход: δ = dL/da · σ'(z). */
        void backward(float dL_da) {
            delta = dL_da * sigmoidDeriv(a);
        }

        /** Шаг градиентного спуска: w -= η·δ·x, b -= η·δ. */
        void update(float[] x) {
            for (int i = 0; i < w.length; i++) w[i] -= LR * delta * x[i];
            b -= LR * delta;
        }
    }

    /** Слой — просто массив нейронов. */
    static class Layer {
        final Neuron[] neurons;

        Layer(int size, int inputSize) {
            neurons = new Neuron[size];
            for (int i = 0; i < size; i++) neurons[i] = new Neuron(inputSize);
        }

        float[] forward(float[] x) {
            float[] y = new float[neurons.length];
            for (int i = 0; i < neurons.length; i++) y[i] = neurons[i].forward(x);
            return y;
        }
    }

    /** Один шаг обучения на одном примере. */
    static void trainOne(Layer hidden, Layer out, float[] x, float[] target) {

        // 1) Прямой проход: сохраняем z и a для backward.
        float[] h = hidden.forward(x);
        float[] y = out.forward(h);

        // 2) Дельта выходного слоя: dL/da = y - target (для MSE),
        //    δ = dL/da · σ'(z).
        for (int k = 0; k < OUT; k++) {
            out.neurons[k].backward(y[k] - target[k]);
        }

        // 3) Дельта скрытого слоя: δ_j = (Σ_k δ_k · w_{jk}) · σ'(z_j).
        for (int j = 0; j < HID; j++) {
            float sum = 0;
            for (int k = 0; k < OUT; k++) {
                sum += out.neurons[k].delta * out.neurons[k].w[j];
            }
            hidden.neurons[j].backward(sum);
        }

        // 4) Обновление весов и смещений.
        for (Neuron n : out.neurons)    n.update(h);
        for (Neuron n : hidden.neurons) n.update(x);
    }

    public static void main(String[] args) {
        // Данные: 4 признака → 3 класса (one-hot).
        float[] x = {5.1f, 3.5f, 1.4f, 0.2f};   // пример «setosa»
        float[] target = {1f, 0f, 0f};

        Layer hidden = new Layer(HID, IN);
        Layer out = new Layer(OUT, HID);

        // Один шаг обучения — чтобы показать, как это работает.
        trainOne(hidden, out, x, target);

        // Проверка: после одного шага выход должен чуть сдвинуться к target.
        float[] y = out.forward(hidden.forward(x));
        System.out.printf("y = [%.4f, %.4f, %.4f]%n", y[0], y[1], y[2]);
    }
}
```

Обратите внимание на алгоритм обучения, то есть [алгоритм обратного распространения ошибки](Глава1.%20Что%20такое%20нейросеть%20и%20зачем%20она%20нужна.md#обратный-проход-обучение)

Итак, для нейронов последнего слоя мы считаем производную потери по выходу:

$$
\frac{\partial L}{\partial a} = a - a^{\text{target}}
$$

и находим дельту ошибки как:

$$
\delta = \frac{\partial L}{\partial z} = \frac{\partial L}{\partial a} \cdot \underbrace{\frac{\partial a}{\partial z}}_{\text{производная функции активации}} = \frac{\partial L}{\partial a} \cdot \sigma'(z)
$$

Для нейронов скрытого слоя находим дельту ошибки как сумму дельт ошибок всех нейронов выходного слоя, с которыми он связан, умноженную на вес связи.

И затем считаем градиент по весу связи:

$$
\frac{\partial L}{\partial w} = \delta \cdot x
$$

изменяем веса для уменьшения функции потерь как:

$$
w_{\text{new}} = w_{\text{old}} - \eta \cdot \frac{\partial L}{\partial w}
$$

соответственно градиент по смещению:

$$
\underbrace{\frac{\partial L}{\partial b}}_{\text{градиент по смещению}} = \delta
$$

Изменяем смещение:

$$
b_{\text{new}} = b_{\text{old}} - \eta \cdot \frac{\partial L}{\partial b}
$$

```text
Epoch  600: loss=0,111045, accuracy=80,0%
Epoch  800: loss=0,096649, accuracy=86,7%

```
Как видите, где-то на 1000-й эпохе точность прекращает расти, но потеря стабильно снижается.
Loss (MSE) штрафует расстояние между выходом и меткой, а accuracy смотрит только на argmax.
Если модель уже правильно классифицирует пример, но с вероятностью 0.7 вместо 0.9, MSE падает, а accuracy не меняется (пример уже «правильный»).
Это не переобучение и не «особенность маленького датасета» — это разная строгость метрик.
Loss «видит» уверенность, accuracy — только ответ.

при MSE + sigmoid loss всегда будет падать, даже когда accuracy стоит, потому что sigmoid «подтягивает» выход к 0 или 1, и MSE это «видит».
Для классификации правильнее использовать CrossEntropy — тогда loss и accuracy согласованы лучше.

Loss на train используется для обучения (градиент).
Метрики на test — для контроля (не переобучилась ли модель).
Если считать метрики только на train, вы не увидите переобучения: train accuracy растёт, а test — падает.
Поэтому test (или валидация) — обязательны

## Нейросеть через матрицы

Вот полный код [IrisMatrix](glava2/code/IrisMatrix.java).
Здесь те же шаги, что и в IrisNeuron, но веса хранятся матрицей [inputSize][outputSize], а смещения — вектором.
Прямой проход — это input × W + b, обратный — те же формулы, что в главе 1, но записанные через индексы матрицы.

```java
 /**
 * Та же сеть, что и IrisNeuron, но через матрицы.
 * Сеть — это набор матриц весов и векторов смещений;
 * прямой проход — умножение вектора на матрицу + активация.
 *
 * Учебный пример: показывает, что матрицы — это та же математика,
 * записанная компактно, без объектов-нейронов.
 */
public class IrisMatrix {

    // -------------------- Размеры и гиперпараметры --------------------
    static final int INPUT_SIZE  = 4;   // 4 признака ириса
    static final int HIDDEN_SIZE = 10;  // скрытый слой
    static final int OUTPUT_SIZE = 3;   // 3 класса
    static final float LEARNING_RATE = 0.01f;

    static final Random RND = new Random(42);

    // -------------------- Параметры сети --------------------
    // Веса: [вход][выход]. Смещения: [выход].
    static float[][] weightsHidden = randomMatrix(INPUT_SIZE,  HIDDEN_SIZE);
    static float[][] weightsOutput = randomMatrix(HIDDEN_SIZE, OUTPUT_SIZE);
    static float[]   biasHidden    = randomVector(HIDDEN_SIZE);
    static float[]   biasOutput    = randomVector(OUTPUT_SIZE);

    // -------------------- Инициализация --------------------

    static float randomWeight() { return RND.nextFloat() * 0.2f - 0.1f; }

    static float[][] randomMatrix(int rows, int cols) {
        float[][] m = new float[rows][cols];
        for (int i = 0; i < rows; i++)
            for (int j = 0; j < cols; j++) m[i][j] = randomWeight();
        return m;
    }

    static float[] randomVector(int size) {
        float[] v = new float[size];
        for (int i = 0; i < size; i++) v[i] = randomWeight();
        return v;
    }

    // -------------------- Активация --------------------

    static float sigmoid(float x) { return 1f / (1f + (float) Math.exp(-x)); }

    static float[] sigmoidAll(float[] values) {
        float[] result = new float[values.length];
        for (int i = 0; i < values.length; i++) result[i] = sigmoid(values[i]);
        return result;
    }

    // -------------------- Матричная операция --------------------

    /**
     * Умножение вектора-строки на матрицу весов плюс смещение:
     * y[j] = b[j] + Σ_i x[i] * W[i][j].
     */
    static float[] multiplyByWeights(float[] input, float[][] weights, float[] bias) {
        int outputSize = weights[0].length;
        float[] result = new float[outputSize];
        for (int j = 0; j < outputSize; j++) {
            float sum = bias[j];
            for (int i = 0; i < input.length; i++) sum += input[i] * weights[i][j];
            result[j] = sum;
        }
        return result;
    }

    // -------------------- Прямой проход --------------------

    static float[] forward(float[] input) {
        float[] hidden = sigmoidAll(multiplyByWeights(input,  weightsHidden, biasHidden));
        return          sigmoidAll(multiplyByWeights(hidden, weightsOutput, biasOutput));
    }

    // -------------------- Один шаг обучения --------------------

    static void trainOne(float[] input, float[] target) {

        /** 1) Прямой проход с сохранением промежуточных значений */
        float[] hiddenPre = multiplyByWeights(input, weightsHidden, biasHidden);
        float[] hidden    = sigmoidAll(hiddenPre);
        float[] outputPre = multiplyByWeights(hidden, weightsOutput, biasOutput);
        float[] output    = sigmoidAll(outputPre);

        /** 2) Дельты выходного слоя: (y - target) · σ'(z) */
        float[] outputDeltas = new float[OUTPUT_SIZE];
        for (int j = 0; j < OUTPUT_SIZE; j++)
            outputDeltas[j] = (output[j] - target[j]) * output[j] * (1 - output[j]);

        /** 3) Дельты скрытого слоя: (δ_out · W_outᵀ) · σ'(z) */
        float[] hiddenDeltas = new float[HIDDEN_SIZE];
        for (int k = 0; k < HIDDEN_SIZE; k++) {
            float weightedSum = 0;
            for (int j = 0; j < OUTPUT_SIZE; j++)
                weightedSum += outputDeltas[j] * weightsOutput[k][j];
            hiddenDeltas[k] = weightedSum * hidden[k] * (1 - hidden[k]);
        }

        /** 4) Обновление выходного слоя: W -= η · δ_out · h, b -= η · δ_out */
        for (int k = 0; k < HIDDEN_SIZE; k++)
            for (int j = 0; j < OUTPUT_SIZE; j++)
                weightsOutput[k][j] -= LEARNING_RATE * outputDeltas[j] * hidden[k];
        for (int j = 0; j < OUTPUT_SIZE; j++)
            biasOutput[j] -= LEARNING_RATE * outputDeltas[j];

        /** 5) Обновление скрытого слоя: W -= η · δ_hidden · x, b -= η · δ_hidden */
        for (int i = 0; i < INPUT_SIZE; i++)
            for (int k = 0; k < HIDDEN_SIZE; k++)
                weightsHidden[i][k] -= LEARNING_RATE * hiddenDeltas[k] * input[i];
        for (int k = 0; k < HIDDEN_SIZE; k++)
            biasHidden[k] -= LEARNING_RATE * hiddenDeltas[k];
    }

    // -------------------- main: один шаг --------------------

    public static void main(String[] args) {
        float[] x      = {5.1f, 3.5f, 1.4f, 0.2f}; // пример «setosa»
        float[] target = {1f, 0f, 0f};

        trainOne(x, target);

        float[] y = forward(x);
        System.out.printf("y = [%.4f, %.4f, %.4f]%n", y[0], y[1], y[2]);
    }
}
```
Те же самые формулы, но уже в матричном виде.

Сравните с IrisNeuron: там `for (Neuron n : layer.neurons) n.update(...)`, здесь — два вложенных цикла по i и k и одно умножение `LEARNING_RATE * hiddenDeltas[k] * input[i]`.
Это то же самое обновление `w -= lr * delta * x`, просто без объектов-нейронов. Выигрыш — в кэше и в том, что внутренние циклы компилятор может векторизовать.

|                              | IrisNeuron                                   | IrisMatrix                                        |
| ---                          | ---                                          | ---                                               |
| Где веса?                    | Внутри каждого нейрона: Neuron.w[i]          | В матрице weightsHidden[i][k] (вход i → выход k)  |
| Где смещение?                | Внутри каждого нейрона: Neuron.b             | В векторе biasHidden[k]                           |
| Сколько объектов?            | HID × OUT нейронов, у каждого свои поля      | Ноль объектов; только массивы float[][] и float[] |

Пример. Скрытый слой 10 → 3:
- IrisNeuron: outLayer.neurons[0]…neurons[9], у каждого w[10] и b.
- IrisMatrix: weightsOutput[10][3] и biasOutput[3].

Данные одни и те же, просто в первом случае они «размазаны» по объектам, а во втором — лежат в матрице.
