# Глава 4. Практика. Решаем задачи mlp-сетями

Функция потерь и выходная активация — это пара. Они выбираются вместе, а не по отдельности.
- Регрессия → Linear на выходе + Mse/Mae.
- Бинарная классификация → Sigmoid + BinaryCrossEntropy.
- Многоклассовая → без активации (логиты) + SoftmaxCrossEntropy.

>„Без активации“ — это не „мы не хотим вероятностей“, а „мы не ставим softmax отдельным слоем, потому что он уже внутри SoftmaxCrossEntropy“. Если вам нужны вероятности на инференсе — примените softmax вручную к логитам. Если поставите Softmax слоем и CrossEntropy — получите двойной softmax и сломанный градиент.

Самая частая ошибка новичков: поставить Sigmoid и Mse, а потом удивляться, почему сеть «залипает».

## Задача аппроксимации значений функции

[апроксимации](tasks/Задачи.md#задача-апроксимации-функции)

Дана неизвестная функция f(x₁, x₂, x₃) → y. 
У нас есть 1000 случайных точек в диапазоне [-2, 2]³ с правильными ответами. 
Сеть должна выучить саму функцию, а не запомнить точки. 
Проверяем на отложенных 10% (SampleSimple.split(dataset, 0.9f)).

Это регрессия: выход — непрерывное число. Значит:
- выходная активация — Linear (или её отсутствие);
- функция потерь — Mse (или Mae).

В коде задачи (FunctionApproximation) есть три сети.

Первая сеть: Sequence + Tanh + MSE.

```java
                200,

m -> {
        // ранняя остановка: R² > 0.99 И RMSE < 0.01
```

Это ошибка выбора пары «лосс ↔ активация».

Tanh насыщается на краях: при tanh(z) → ±1 производная 1 - tanh² → 0. 
Если сеть уверена в ответе около 0 или 1, градиент по выходу затухает, и обучение «залипает» у краёв.

Mse ожидает линейного выхода. 
Композиция Mse ∘ Tanh даёт градиент 2·(tanh(z) - t)·(1 - tanh²(z)) — произведение двух множителей, каждый из которых может быть мал.

Как надо: для регрессии на выходе — Linear (или ActivationLayer с Linear, или просто без активации после Dense). Сеть сама подстроит диапазон через веса.

```java
                },
```


Здесь собраны все правильные решения для регрессии:

| Решение | Выбор | Почему |
| --- | --- | --- |
| Архитектура | Functional (через LayerSpec) | Хотя цепочка линейная, Functional даёт единый интерфейс для будущих усложнений (skip‑связи, ветвление) |
| Активация | LeakyReLU | Нет насыщения, «мёртвых нейронов» нет, градиент не затухает |
| Глубина | 64 → 32 → 1 | Два скрытых слоя достаточно для нелинейной функции от 3 переменных; больше — риск переобучения на 1000 точек |
| Выход | Dense(1) без активации | Линейный выход для регрессии |
| Лосс | Mse | Стандарт для регрессии |
| Оптимизатор | AdamW(0.001f) | Адаптивный шаг, устойчив к разному масштабу весов, быстро сходится |
| Клипинг | -1f (выключен) | Для маленькой сети и AdamW не нужен |


## Задача классификации ирисов

[ирисов](tasks/Задачи.md#задача-классификации-ирисов)

150 примеров, 4 признака (длина/ширина чашелистика и лепестка), 3 класса. Это многоклассовая классификация: выход — вектор из 3 чисел, где 1 стоит на позиции правильного класса (one-hot).

Ключевое отличие от регрессии: выход — не число, а распределение по классам. Значит:
- выходная активация — никакой (логиты!);
- лосс — SoftmaxCrossEntropy (он сам делает softmax внутри и даёт численно устойчивый градиент p - t).

```java
        Sequence.of(List.of(
                new Sequence.InputDto(4),
                new DenseLayer.Dto(8), new ActivationLayer.Dto(new Tanh()),     // скрытый: Tanh (или LeakyRelu)
                new DenseLayer.Dto(3)                                           // логиты, без активации
        )).train(
                150, dataset,
                new SoftmaxCrossEntropy(),                      // правильный лосс для one-hot
                new Momentum(0.01f, 0.9f) ,        // (или AdamW(0.001f))
                32,
                5,
                List.of(new Accuracy()),
                m -> m.get(0).result() > 0.95f ,                // ранняя остановка
                1f
        );
```

Почему именно так — по пунктам:
- Sequence, а не Functional. Задача линейная: 4 → 8 → 3. Ветвление и skip-связи не нужны, Sequence проще и быстрее. Functional здесь был бы оверинжинирингом — платить сложностью DSL за линейную сеть незачем.
- Dense(8) — узкий скрытый слой. У нас всего 150 примеров и 4 признака. Слой на 64 нейрона мгновенно переобучится: запомнит тренировочные точки. Правило: ширина скрытого слоя соизмерима с числом признаков и объёмом данных. 8 нейронов — разумно; 16 — тоже допустимо; 64 — уже риск.
- Tanh в скрытом слое. Данные — 4 непрерывных признака в примерно одном масштабе (после деления на 10). Tanh центрирован около нуля, даёт сильные градиенты, хорошо разделяет классы. LeakyReLU тоже сработал бы; Sigmoid — хуже (насыщение на глубоких сетях, но здесь сеть мелкая, так что разница невелика).
- Dense(3) БЕЗ активации — это принципиально. На выходе — сырые логиты (числа до softmax). SoftmaxCrossEntropy ожидает именно логиты: он сам применяет max-trick softmax внутри loss и derivative, и возвращает градиент dL/dz = p - t прямо в Dense.backward. Никакого промежуточного SoftmaxLayer/SigmoidLayer не нужно — и не должно быть.
- Правило: SoftmaxCrossEntropy ⇒ логиты на выходе. Если поставить Softmax или Sigmoid перед ним, получите двойную нормализацию: softmax от softmax, или BCE-подобный градиент поверх уже сжатых в (0,1) чисел — численная нестабильность и плохая сходимость.
- Momentum(0.01, 0.9). Небольшой learning rate 0.01 + импульс 0.9. Для маленькой задачи AdamW тоже подошёл бы (0.001f), но Momentum здесь показывает классический SGD-подход: медленнее стартует, но устойчивее в конце. На 150 примерах разница невелика — оба варианта дадут ~95–98% accuracy.
- Accuracy — правильная метрика. Для классификации accuracy интерпретируема («доля правильных ответов»), в отличие от RMSE, который на one-hot векторах даёт странные числа. Accuracy.classify для вектора длины > 1 берёт argmax и сравнивает с argmax таргета — то есть корректно работает именно с логитами (порядок argmax не меняется под действием softmax).
- Early stop > 0.95f. На ирисах 95% — реалистичный порог. 100% на тесте — почти наверняка переобучение (150 примеров — слишком мало, чтобы доверять идеальному результату).
- Клипинг 1f. Для Momentum глобальный gradient clipping по L2-норме полезен: импульс может «разгонять» шаг при смене направления, и клипинг страхует от взрыва. Для AdamW (-1f) он обычно не нужен — адаптивный шаг сам нормализует.

Разбор решения
- 784 → 256 → 128 → 10. Классическая «воронка»: широкий вход, сужение к выходу. 256 нейронов — разумный старт для MNIST (меньше — недообучение, больше — переобучение без Dropout).
- LeakyReLU, а не Tanh/Sigmoid. На MNIST глубокие сети с Tanh/Sigmoid страдают от затухающих градиентов. LeakyReLU не насыщается и не «убивает» нейроны (в отличие от ReLU с alpha=0).
- Dropout(0.2) после каждого скрытого слоя. Регуляризация: во время обучения 20% нейронов случайно «выключаются», сеть не полагается на отдельные нейроны. На инференсе dropout — тождество. Это ключевой приём против переобучения на MNIST.
- AdamW(0.001f). MNIST с AdamW сходится за 10–30 эпох. SGD без momentum потребовал бы тюнинга learning rate и больше эпох.
- Клипинг -1f (выключен). AdamW сам нормализует шаг по vHat, поэтому глобальный клипинг не критичен. Для SGD/Momentum клипинг 1f был бы полезен.
- Early stop > 0.98f. 98% на MNIST — достижимо для MLP. 99%+ обычно требует CNN.

MLP_fun — это residual-архитектура (с AddSpec), которая должна учиться лучше, чем MLP_seq, но (из-за простоты задачи), в нашем случае проигрывает mlp_seq
```text
x → dense(784→256) → h
h → LeakyReLU → dense(256→256) → h2
r = h + h2        // <-- остаточная связь
r → dense(256→10)
```

Residual (остаточная связь) — это приём, который позволяет обучать очень глубокие сети, не теряя градиент.

Обычный слой учится функции H(x).

Residual-блок учится разности (остатку) F(x) = H(x) - x

А выход блока считается как y=F(x)+x

То есть мы прибавляем вход к выходу.
Сеть не обязана «с нуля» выучивать полезное преобразование — ей достаточно выучить поправку к исходному x.

Градиент при обратном распространении идёт через + напрямую (производная от x равна 1). Он не проходит через веса слоёв и активации, поэтому не затухает. В глубоких сетях (50, 100+ слоёв) без residual градиент просто «умирает» по пути назад, и первые слои не учатся. Residual даёт градиенту «шоссе» в обход.

По хорошему здесь residual не нужен: на MNIST с 2–3 слоями деградации ещё нет, и mlp_seq обычно не хуже. 
Residual-связи раскрываются на глубоких сетях (10+ слоёв), где без них обучение просто не идёт. 
Здесь mlp_fun — учебная демонстрация механизма.
