# Глава 3. Архитектура нейросети

В [главе 2](Глава%202.%20Пишем%20нейросети%20сами.md) мы написали пару сетей «в лоб»: одна — объектная, другая — матричная.
Обе работают, но у них есть проблема: каждая сеть — это отдельный класс со своими полями weights, biases и циклом forward.
Добавить новый слой — переписать сеть. Собрать сеть из блоков — переписать сеть.
Вложить одну сеть в другую — переписать сеть.

Архитектура решает три задачи:
- Единый контракт слоя. Любой слой — это forward, backward, zeroGrad, update, save, load. Сеть работает с Layer, а не с конкретными классами.
- Сборка из блоков. Сеть — это последовательность слоёв/блоков (меньших сетей) (Sequence) или граф (Functional). Слои можно переставлять, вкладывать, ветвить.
- Сериализация. Сохранили сеть — загрузили — получили ту же сеть с теми же весами.


## Контракты

### Контракт Model

[model](../../../../code/net/model/Model.java)

Model — это что угодно, что умеет делать forward, обучаться и сериализоваться.
Не важно, Sequence это или Functional — пользователь работает с интерфейсом.

Model состоит из слоёв или из блоков (каждый блок также model и может рассматриваться как слой с точки зрения верхнеуровневой сети).

```java
public interface Model {
    // --- вычисления ---
    float[] forward(float[] input, boolean training);
    default float[] forward(float[] input) { return forward(input, false); }

    // --- слоевой контракт (нужен, чтобы вкладывать модель в другую) ---
    default float[] backward(float[] deltaNext) { throw new UnsupportedOperationException(); }
    default void zeroGrad() { throw new UnsupportedOperationException(); }
    default void update(Optimizer optimizer, int batchSize) { throw new UnsupportedOperationException(); }
    default double gradNormSq() { return 0.0; }
    default void scaleGrad(float scale) {}

    // --- обучение ---
    Model train(int maxEpoch, SampleSimple.Dataset ds, Loss loss, Optimizer optimizer,
                int batchSize, int showTestCount, List<Metric> metrics,
                Predicate<List<Metric>> endPredicate, float clipNorm);

    Model test(List<SampleSimple> samples, List<Metric> metrics);

    // --- формы ---
    TensorShape inputShape();
    TensorShape outputShape();

    // --- сериализация ---
    void save(Path path);
    default void save(DataOutputStream out) throws IOException { throw new UnsupportedOperationException(); }
    static Model load(Path path) { ... }
    static Model load(DataInputStream in) throws IOException { ... }
}
```

### Контракт Layer

Слой — это атомарный строительный блок. У него есть форма входа, форма выхода и четыре операции.

```java
public abstract class Layer {
    protected TensorShape inputShape;
    protected TensorShape outputShape;

    // --- фабрика ---
    public abstract static class Dto {
        public abstract Layer create(TensorShape inputShape);
    }
    public abstract Layer allocateBuffers();
    public Layer initWeights(Activate activate) { throw new UnsupportedOperationException(); }

    // --- формы ---
    public final TensorShape inputShape()  { return inputShape; }
    public final TensorShape outputShape() { return outputShape; }

    // --- вычисления ---
    public abstract float[] forward(float[] input, boolean training);
    public abstract float[] backward(float[] deltaNext);

    // --- веса ---
    public void zeroGrad() {}
    public void update(Optimizer optimizer, int batchSize) {}

    // --- клипинг ---
    public double gradNormSq() { return 0.0; }
    public void scaleGrad(float scale) {}

    // --- сериализация ---
    public void save(DataOutputStream out) throws IOException { ... }
    public void load(DataInputStream in) throws IOException { ... }
}
```

- Dto и create. Слой создаётся из DTO, а не напрямую. DTO знает архитектурные параметры (outputSize, kernelSize, ...), но не знает форму входа — она приходит из предыдущего слоя. Это позволяет собирать сеть «сверху вниз»: каждый слой получает форму от предыдущего.
- backward накапливает градиенты. Не перезаписывает, а прибавляет. Это критично для батчей: за батч backward вызывается N раз, и градиенты суммируются. update потом делит на batchSize.
- forward может вернуть алиас input. Контракт разрешает слою вернуть тот же массив, что и на входе (например, ActivationLayer может писать в тот же буфер). Вызывающий код не должен рассчитывать на отдельный буфер.

```java
// Dto знает "128 нейронов", но не знает "вход 784"
new DenseLayer.Dto(128);  // ждёт inputShape

// create(inputShape) соединяет Dto с формой входа
Layer layer = dto.create(TensorShape.flat(784));  // теперь знает: 784 → 128
```

### TensorShape - форма данных

[TensorShape](../../../../code/net/TensorShape.java)

Разные типы слоёв (mlp, cnn, rnn, другие) хотят на вход разные виды данных.
Для mlp это плоский массив. Для cnn - уже двухмерный (картника) или даже трёхмерный если цветовой канал (RGB - read, gree, blue) это отдельное измерение и так далее.
Понятно что всё это можно выразить через плоский массив, но из слоя в слой надо как-то передавать его форму.

Это что-то вроде [Strided view](../../../base/math/Тензор.%20Strided%20viev.md) нормального тензора но без его преимуществ вроде [autograd](../../../base/math/Тензор.%20Autograd.md) и ускорения некотрых опреаций за над ним за счёт изменения формы.
В нашем случае форма тензора используется только чтобы удобнее передавать инфомрацию между слоями об их входах\выходах чтобы можно было правильно "соединить" слои в сеть.

| Вид | Пример | Что это |
| --- | --- | --- |
| flat(N) | flat(784) | плоский вектор (MLP‑вход, MNIST) |
| cnn(C,H,W) | cnn(3,224,224) | карта признаков (CNN) |
| seq(T,d) | seq(128,256) | последовательность (Transformer/RNN) |

```java
public record TensorShape(int channels, int height, int width, int seqLen) {
    public TensorShape {
        if (channels < 1 || height < 1 || width < 1)
            throw new IllegalArgumentException("Некорректная форма");
        if (seqLen > 0 && (height != 1 || width != 1))
            throw new IllegalArgumentException("sequence-форма требует H=W=1");
    }

    public static TensorShape flat(int size)            { return new TensorShape(size, 1, 1, 0); }
    public static TensorShape cnn(int c, int h, int w)  { return new TensorShape(c, h, w, 0); }
    public static TensorShape seq(int t, int d)         { return new TensorShape(d, 1, 1, t); }

    public int size() { return channels * height * width * (seqLen == 0 ? 1 : seqLen); }
    public boolean isFlat()     { return height == 1 && width == 1 && seqLen == 0; }
    public boolean isSequence() { return seqLen > 0; }
    public boolean isCnn()      { return !isFlat() && !isSequence(); }
}
```

## Sequence — линейная сеть

[sequence](../../../../code/net/model/sequence/Sequence.java)

Самая простая реализация Model: массив слоёв, forward по цепочке, backward в обратном порядке.

```java
public class Sequence implements Model {
    private final Layer[] layers;
    private final float[] outputGradient;  //выделили один раз просто чтобы не перевыделять каждый раз при обучении. Для ускорения

    private Sequence(List<Layer> layers) {
        this.layers = layers.toArray(new Layer[0]);
        this.outputGradient = new float[layers.getLast().outputShape().size()];
    }

    public static Sequence of(List<Layer.Dto> dtos) {
        if (dtos.size() < 2) throw new IllegalArgumentException("Нужно >= 2 слоя");
        if (!(dtos.getFirst() instanceof InputDto)) throw new IllegalArgumentException("Первый — InputDto");

        TensorShape currentShape = ((InputDto) dtos.getFirst()).shape;
        List<Layer> layers = new ArrayList<>();
        for (int i = 1; i < dtos.size(); i++) {
            Layer layer = dtos.get(i).create(currentShape);
            currentShape = layer.outputShape();
            layers.add(layer);
        }
        return new Sequence(layers);
    }

    @Override
    public float[] forward(float[] input, boolean training) {
        float[] current = input;
        for (Layer layer : layers) current = layer.forward(current, training);
        return current;
    }

    @Override
    public float[] backward(float[] deltaNext) {
        float[] delta = deltaNext;
        for (int l = layers.length - 1; l >= 0; l--) delta = layers[l].backward(delta);
        return delta;
    }

    @Override public void zeroGrad()                          { for (Layer l : layers) l.zeroGrad(); }
    @Override public void update(Optimizer opt, int batch)     { for (Layer l : layers) l.update(opt, batch); }
    @Override public TensorShape inputShape()  { return layers[0].inputShape(); }
    @Override public TensorShape outputShape() { return layers[layers.length - 1].outputShape(); }
}
```

Обучение
```java
public Sequence train(int maxEpoch, SampleSimple.Dataset ds, Loss loss, Optimizer optimizer,
                      int batchSize, int showTestCount, List<Metric> metrics,
                      Predicate<List<Metric>> endPredicate, float clipNorm) {

    // Проверка корректности размера батча: он должен быть хотя бы 1
    if (batchSize < 1) throw new IllegalArgumentException("batchSize >= 1");

    // Если список метрик не передан, создаём дефолтный — только метрика по функции потерь
    if (metrics == null) metrics = List.of(new LossMetric(loss));

    // Копируем обучающую выборку в изменяемый список, чтобы можно было перемешивать
    List<SampleSimple> trainSamples = new ArrayList<>(ds.getTrainSamples());
    int trainSize = trainSamples.size();

    // Основной цикл по эпохам обучения
    for (int epoch = 0; epoch < maxEpoch; epoch++) {
        // Перемешиваем обучающие примеры для лучшей сходимости и избежания смещений
        Collections.shuffle(trainSamples);

        // Проходим по всем данным батчами
        for (int start = 0; start < trainSize; start += batchSize) {
            // Вычисляем конец текущего батча (не выходя за границы списка)
            int end = Math.min(start + batchSize, trainSize);
            int currentBatchSize = end - start;

            // Обнуляем градиенты перед новым шагом обратного распространения
            zeroGrad();

            // Проходим по примерам в текущем батче
            for (int i = start; i < end; i++) {
                SampleSimple sample = trainSamples.get(i);
                // Прямой проход: получаем предсказания модели
                float[] outputs = this.forward(sample.getInputs(), true);
                // Обратный проход: вычисляем градиенты на основе целевых значений и функции потерь
                this.backward(outputs, sample.getTargets(), loss);
            }

            // Применяем ограничение нормы градиентов (gradient clipping) для стабильности обучения
            applyGlobalClipOfNorm(clipNorm, currentBatchSize);

            // Обновляем веса модели с помощью оптимизатора
            update(optimizer, currentBatchSize);
        }

        // Тестируем модель на валидационной/тестовой выборке
        test(ds.getTestSamples(), metrics);
        // Логируем результаты текущей эпохи
        log.info("Эпоха обучения {}. Метрики {}", epoch, Metric.print(metrics));

        // Проверяем условие досрочной остановки или завершаем, если достигнута последняя эпоха
        if (epoch == maxEpoch - 1 || (endPredicate != null && endPredicate.test(metrics))) {
            // При необходимости выводим примеры тестовых предсказаний
            printTestSample(showTestCount, ds.getTestSamples(), log);
            break;
        }
    }

    // Возвращаем текущий объект (паттерн builder/fluent interface)
    return this;
}
```

## Functional — сеть как граф

[functional](../../../../code/net/model/functional/Functional.java)

«Sequence — это цепочка: x → h1 → h2 → y.
У каждого слоя один вход и один выход.

Functional — это направленный ациклический граф (DAG): узел может иметь несколько входов (residual: x + h), несколько выходов (multi-head: y1, y2), и ветвиться (одна ветвь — residual, другая — main).

Как это работает:
- Граф — это набор узлов, каждый узел — это слой или merge (сложение, конкатенация).
- Forward идёт по узлам в топологическом порядке (от входа к выходу).
- Backward идёт в обратном порядке и накапливает дельты в deltaAccum: если узел используется дважды (residual), его дельта — сумма дельт от обоих потребителей.

Вот вся идея вычислительного графа.

Узел
```java
public static final class Node {
    public final String name;
    public Layer layer;             // null, если это merge или input
    public final Merge merge;       // null, если это слой или input
    public final List<Node> inputs; // родители в графе
    public final TensorShape shape;

    float[] output;       // результат последнего forward
    float[] deltaAccum;   // накопленный градиент
}
```

Граф собирается через Functional.Builder.
```java
Functional.Builder b = Functional.builder(TensorShape.flat(784));
Functional.Node x = b.input();

Functional.Node h = b.layer(new DenseLayer.Dto(TensorShape.flat(128)), x);
h = b.layer(new ActivationLayer.Dto(new LeakyRelu()), h);

Functional.Node out = b.layer(new DenseLayer.Dto(TensorShape.flat(10)), h);
Functional model = b.output(out);
```

Ключевые методы Builder:

| Метод | Что делает |
| --- | --- |
| input() | корневой узел |
| layer(dto, src) | добавляет слой поверх src |
| dense(src, units) | сахар для DenseLayer |
| activation(src, act) | сахар для ActivationLayer |
| add(a, b) | Merge.ADD — поэлементная сумма |
| mul(a, b) | Merge.MUL — поэлементное произведение (для гейтов) |
| concat(a, b) | конкатенация |
| model(model, src) | вложить готовую Model как слой |
| output(node) | завершает граф |

Forward и backward
```java
@Override
public float[] forward(float[] input, boolean training) {
    inputNode.output = input;
    for (Node n : topo) {
        if (n == inputNode) continue;
        float[] x;
        if (n.merge != null) {
            List<float[]> ins = n.inputs.stream().map(p -> p.output).toList();
            n.merge.setLastInputs(ins);
            x = n.merge.forward(ins);
        } else {
            x = n.inputs.get(0).output;
        }
        n.output = (n.layer != null) ? n.layer.forward(x, training) : x;
    }
    return outputNode.output;
}

private void backwardGraph(float[] deltaOut) {
    for (Node n : topo) n.deltaAccum = null;
    outputNode.deltaAccum = deltaOut.clone();

    for (int i = topo.size() - 1; i >= 0; i--) {
        Node n = topo.get(i);
        if (n.deltaAccum == null) continue;

        float[] d = n.deltaAccum;
        float[] dIn = (n.layer != null) ? n.layer.backward(d) : d;

        if (n.merge != null) {
            List<float[]> split = n.merge.backward(dIn);
            for (int k = 0; k < n.inputs.size(); k++)
                accumulateDelta(n.inputs.get(k), split.get(k));
        } else if (n.inputs.size() == 1) {
            accumulateDelta(n.inputs.get(0), dIn);
        }
    }
}

//Backward идёт по topo в обратном порядке, накапливает дельты в deltaAccum:
private static void accumulateDelta(Node n, float[] d) {
    if (n.deltaAccum == null) n.deltaAccum = d.clone();
    else for (int j = 0; j < d.length; j++) n.deltaAccum[j] += d[j];
}
```

Почему accumulateDelta, а не присваивание.
Представьте residual: y = x + h, где h = f(x).
В forward x используется дважды: как вход в f и как слагаемое.
В backward x получает дельту от f и от сложения. Если бы мы присваивали — одна из дельт потерялась бы.
Поэтому — накапливаем. Это правило цепочки для ветвления:

$$
\frac{\partial L}{\partial x} = \frac{\partial L}{\partial h} \cdot \frac{\partial h}{\partial x} + \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial x}
$$

Обучение
```java
    @Override
    public Functional train(int maxEpoch, SampleSimple.Dataset ds, Loss loss, Optimizer optimizer,
                       int batchSize, int showTestCount, List<Metric> metrics,
                       Predicate<List<Metric>> endPredicate, float clipNorm) {
        if (batchSize < 1) throw new IllegalArgumentException("batchSize >= 1");
        if (metrics == null) metrics = List.of(new LossMetric(loss));

        List<SampleSimple> data = new ArrayList<>(ds.getTrainSamples());// Копируем train-выборку, чтобы перемешивать её, не трогая исходный Dataset.
        Random rnd = new Random(42L);
        float[] dOut = new float[outSize];// Переиспользуемый буфер под dL/dy, чтобы не аллоцировать его на каждом примере.

        for (int epoch = 0; epoch < maxEpoch; epoch++) {
            Collections.shuffle(data, rnd);

            // Идём по выборке мини-батчами: [start, end).
            for (int start = 0; start < data.size(); start += batchSize) {
                int end = Math.min(start + batchSize, data.size());  // Последний батч эпохи может быть короче batchSize.
                int actualBatch = end - start;

                // Обнуляем накопители градиентов всех слоёв перед новым батчем.
                zeroGrad();

                // Накопление градиентов по всем примерам батча:
                // forward(training=true) → loss.derivative → backward.
                // Градиенты суммируются (не усредняются) — усреднение делает update(batchSize).
                for (int k = start; k < end; k++) {
                    SampleSimple s = data.get(k);
                    float[] y = forward(s.getInputs(), true);
                    loss.derivative(y, s.getTargets(), dOut);
                    backward(dOut);
                }

                // Глобальный gradient clipping: норма накопленных градиентов растёт ~в actualBatch раз,
                // поэтому порог clipNorm (на пример) умножается на фактический размер батча.
                applyGlobalClip(clipNorm, actualBatch);

                // Один шаг оптимизатора на батч; batchSize нужен для усреднения накопленных градиентов.
                update(optimizer, actualBatch);
            }

            test(ds.getTestSamples(), metrics);
            log.info("Эпоха обучения {}. Метрики {}", epoch, Metric.print(metrics));
            if (epoch == maxEpoch - 1 || (endPredicate != null && endPredicate.test(metrics))) {
                printTestSample(showTestCount, ds.getTestSamples(), log);
                break;
            }
        }
        return this;
    }
```

DSL для Functional:

DSL (NetSpec и его реализации) решает это: сеть описывается декларативно, как композиция спецификаций. Мемоизация гарантирует, что общий ствол строится один раз, а RefSpec позволяет ссылаться на уже построенный узел по имени.

Важно. DSL — это макрос над графом. Он живёт только на этапе сборки.
После build() вы получаете обычный Functional — с узлами, слоями, весами.
Сериализуется именно Functional, а не spec'и.
Поэтому DSL не нужно учить «наизусть» — достаточно понимать три вещи: InputSpec, LayerSpec, NamedSpec/RefSpec.

«DSL не обязателен: можно собирать Functional напрямую через Builder (как в разделе выше).
DSL нужен, когда граф сложный (residual, multi-head, общий ствол) и ручная сборка становится утомительной.

**InputSpec — корень**
```java
NetSpec net = new LayerSpec(
        new InputSpec(784),                        // корень: flat(784)
        new DenseLayer.Dto(TensorShape.flat(64)),
        new ActivationLayer.Dto(new LeakyRelu())
);
Functional model = net.build();
```

InputSpec — единственный spec, у которого inputShape() != null.
Он «занимает» корневой узел Builder.input() и может быть использован только один раз в одном билдере.
Повторное использование бросит IllegalStateException.

Для переиспользования входа есть NamedSpec + RefSpec.

**LayerSpec — последовательность**
```java
NetSpec net = new LayerSpec(
        new InputSpec(784),
        new DenseLayer.Dto(TensorShape.flat(128)),
        new ActivationLayer.Dto(new LeakyRelu()),
        new DropoutLayer.Dto(0.2f),
        new DenseLayer.Dto(TensorShape.flat(10)),
        new ActivationLayer.Dto(new Sigmoid())
);
```

LayerSpec(prev, steps...) — это «применить шаги поверх prev». Шаг — либо Layer.Dto (обычный слой), либо вложенный NetSpec (подграф).

Это точный аналог Sequence.of(...), но в мире Functional. Разница: LayerSpec можно вложить в другой LayerSpec, и тогда получится дерево.

**NamedSpec + RefSpec — переиспользование**
```java
// общий ствол
NetSpec x  = new NamedSpec("x", new InputSpec(784));
NetSpec h  = new LayerSpec(x,
        new DenseLayer.Dto(TensorShape.flat(64)),
        new ActivationLayer.Dto(new LeakyRelu()));

// две ветви от одного ствола
NetSpec branchA = new LayerSpec(h, new DenseLayer.Dto(TensorShape.flat(10)));
NetSpec branchB = new LayerSpec(h, new DenseLayer.Dto(TensorShape.flat(4)));

// слить в один выход
NetSpec merged = new ConcatSpec(branchA, branchB);
Functional model = merged.build();
```

Практические паттерны

Паттерн 1: ResNet-блок
```java
NetSpec x = new NamedSpec("x", new InputSpec(784));

NetSpec main = new LayerSpec(new RefSpec("x"),
        new DenseLayer.Dto(TensorShape.flat(64)),
        new ActivationLayer.Dto(new LeakyRelu()),
        new DenseLayer.Dto(TensorShape.flat(64)));

NetSpec res = new AddSpec(main, new RefSpec("x"));       // main + x

Functional model = res.build();
```
RefSpec("x") используется дважды: как вход main и как второй аргумент AddSpec. При backward градиент по x — сумма двух вкладов. Это residual.

Паттерн 2: две головы от общего ствола
```java
NetSpec trunk = new NamedSpec("trunk", new LayerSpec(
        new InputSpec(784),
        new DenseLayer.Dto(TensorShape.flat(128)),
        new ActivationLayer.Dto(new LeakyRelu())));

NetSpec headA = new LayerSpec(new RefSpec("trunk"), new DenseLayer.Dto(TensorShape.flat(10)));
NetSpec headB = new LayerSpec(new RefSpec("trunk"), new DenseLayer.Dto(TensorShape.flat(4)));

NetSpec merged = new ConcatSpec(headA, headB);           // 10 + 4 = 14

Functional model = merged.build();
```
trunk строится один раз. headA и headB сидят на одном узле — веса общие. Это стандартный паттерн multi-task learning.

Паттерн 3: несколько выходов через MultiSpec
```java
NetSpec trunk = new NamedSpec("trunk", new LayerSpec(
        new InputSpec(784),
        new DenseLayer.Dto(TensorShape.flat(128))));

NetSpec logits = new NamedSpec("logits",
        new LayerSpec(new RefSpec("trunk"), new DenseLayer.Dto(TensorShape.flat(10))));
NetSpec aux = new NamedSpec("aux",
        new LayerSpec(new RefSpec("trunk"), new DenseLayer.Dto(TensorShape.flat(4))));

MultiSpec multi = new MultiSpec(
        new LayerSpec(trunk, new DenseLayer.Dto(TensorShape.flat(1))),  // заглушка-корень
        "logits", "aux");

Functional.Builder b = Functional.builder(TensorShape.flat(784));
List<Functional.Node> heads = multi.buildOutputs(b);     // [logits, aux]
```
Зачем заглушка-корень. MultiSpec требует inner с одним входом. Заглушка new LayerSpec(trunk, new DenseLayer.Dto(TensorShape.flat(1))) — это «ствол + фиктивная голова», чтобы у inner был корневой узел. Сами головы (logits, aux) — отдельные NamedSpec, которые MultiSpec находит по именам.

Паттерн 4: вложенная модель как блок
```java
Model encoder = ...;                                     // обученный энкодер
NetSpec net = new LayerSpec(
        new ModelSpec(new InputSpec(encoder.inputShape()), encoder, false),  // trainable=false
        new DenseLayer.Dto(TensorShape.flat(10)));

Functional model = net.build();
```
ModelSpec(prev, model, trainable) вкладывает Model как слой. trainable=false — заморозка: zeroGrad/update/scaleGrad — no-op, gradNormSq возвращает 0. Градиент при этом проходит сквозь блок (backward работает), иначе слои перед блоком не смогли бы обучаться.

## Реальные слои

### DenseLayer — полносвязный

Самый важный слой. y = W·x + b.

>Сравнивая с класом Neiron из [IrisNeuron](glava2/code/IrisNeuron.java)
>
> Neuron.forward: z = b + Σ w[i]·x[i], один нейрон.
>
>DenseLayer.forward: z[i] = b[i] + Σ w[i][j]·x[j], весь слой сразу.
>
> DenseLayer — это тот же Neuron, но векторизованный по всем нейронам слоя. backward — тот же Neuron.backward, но с накоплением градиентов по батчу (biasGrad[i] += d, wg[j] += d · input[j]).

```java
public class DenseLayer extends Layer {
    float[][] weights;   // [outputSize][inputSize]
    float[] biases;      // [outputSize]
    private float[][] weightGrad;
    private float[] biasGrad;

    private float[] input;       // вход последнего forward
    private float[] output;
    private float[] prevDelta;

    @Override
    public Layer allocateBuffers() {
        if (!inputShape.isFlat() || !outputShape.isFlat())
            throw new IllegalArgumentException("DenseLayer хочет плоские вход и выход");
        int in = inputShape.size(), out = outputShape.size();
        weights    = new float[out][in];
        biases     = new float[out];
        weightGrad = new float[out][in];
        biasGrad   = new float[out];
        output     = new float[out];
        prevDelta  = new float[in];
        return this;
    }

    @Override
    public float[] forward(float[] input, boolean training) {
        this.input = input;
        for (int i = 0; i < outputShape.size(); i++) {
            float sum = biases[i];
            float[] w = weights[i];
            for (int j = 0; j < input.length; j++) sum += w[j] * input[j];
            output[i] = sum;
        }
        return output;
    }

    @Override
    public float[] backward(float[] deltaNext) {
        Arrays.fill(prevDelta, 0f);
        for (int i = 0; i < outputShape.size(); i++) {
            float d = deltaNext[i];
            biasGrad[i] += d;
            float[] w = weights[i], wg = weightGrad[i];
            for (int j = 0; j < input.length; j++) {
                prevDelta[j] += w[j] * d;
                wg[j]       += d * input[j];
            }
        }
        return prevDelta;
    }

    @Override public void zeroGrad() { /* обнулить weightGrad, biasGrad */ }
    @Override public void update(Optimizer opt, int batch) { opt.update(weights, weightGrad, biases, biasGrad, batch); }
}
```

### ActivationLayer — поэлементная активация

Слой без параметров. y = f(x).

```java
public class ActivationLayer extends Layer {
    private Activate activate;
    private float[] out, prevDelta, deriv, lastInput;

    @Override
    public float[] forward(float[] input, boolean training) {
        System.arraycopy(input, 0, lastInput, 0, input.length); // копия: activate может писать в input
        activate.apply(input, out);
        return out;
    }

    @Override
    public float[] backward(float[] deltaNext) {
        activate.derivative(lastInput, out, deriv);
        for (int i = 0; i < deltaNext.length; i++)
            prevDelta[i] = deltaNext[i] * deriv[i];
        return prevDelta;
    }

    @Override public void zeroGrad() {}                 // нечего обнулять
    @Override public void update(Optimizer o, int b) {} // нечего обновлять
}
```

### DropoutLayer — регуляризация

Слой без параметров, но с состоянием: маска, сгенерированная на forward.

```java
public class DropoutLayer extends Layer {
    private float p;
    private float[] out, prevDelta, mask;
    private boolean lastTraining;

    @Override
    public float[] forward(float[] input, boolean training) {
        this.lastTraining = training;
        if (!training || p == 0f) {
            System.arraycopy(input, 0, out, 0, input.length);
            return out;
        }
        float keep = 1f - p, scale = 1f / keep;
        Random rnd = ThreadLocalRandom.current();
        for (int i = 0; i < input.length; i++) {
            if (rnd.nextFloat() < keep) { mask[i] = scale; out[i] = input[i] * scale; }
            else                        { mask[i] = 0f;    out[i] = 0f; }
        }
        return out;
    }

    @Override
    public float[] backward(float[] deltaNext) {
        if (!lastTraining || p == 0f) System.arraycopy(deltaNext, 0, prevDelta, 0, deltaNext.length);
        else for (int i = 0; i < deltaNext.length; i++) prevDelta[i] = deltaNext[i] * mask[i];
        return prevDelta;
    }
}
```

Почему маска хранится. Forward «выключил» часть нейронов. Backward должен пропустить градиент только через выживших.
Если маску не сохранить — backward не узнает, какие позиции были обнулены.

## Шпаргалка по подбору параметров сети

### Функция потери (loss)

| Задача | Лосс | Выходной слой |
| --- | --- | --- |
| 1 из N классов | SoftmaxCrossEntropy | DenseLayer (Linear, N нейронов) |
| Мульти-метка (несколько классов одновременно) | BinaryCrossEntropy | DenseLayer + Sigmoid, N нейронов |
| Бинарная классификация | BinaryCrossEntropy | DenseLayer + Sigmoid, 1 нейрон |
| Регрессия, выбросы не важны | Mse | Linear |
| Регрессия, выбросы важны | Mae / Huber | Linear |
| Не использовать | Mae для классификации; Mae с Sigmoid‑выходом | — |

### Активация скрытых слоёв

| Ситуация | Активация |
| --- | --- |
| Стандарт | LeakyRelu |
| Хочется центрированных градиентов | Tanh |
| RNN | Tanh |
| Не использовать | Sigmoid в глубоких скрытых слоях |

### Оптимизатор

| Ситуация | Оптимизатор |
| --- | --- |
| Хочу контролировать каждый шаг | SGD + LR‑schedule |
| «Работает из коробки» | Momentum или AdamW |
| Мало данных, шум | AdamW (адаптивный) |
| Не хочу подбирать LR | AdamW(0.001f) |
| Хочу L2‑регуляризацию | AdamW (weight decay) |

### Гиперпараметры

| Параметр | Значение | Комментарий |
| --- | --- | --- |
| batchSize | 16–32 | 1 — плохо, >128 — нужен больший LR |
| lr для SGD | 0.01 | При увеличении batch — масштабировать |
| lr для AdamW | 0.001 | Адаптивный, много не надо |
| Эпох | 30–100 | Лучше с early stop по метрике |

- Лосс и выход связаны жёстко. SoftmaxCrossEntropy требует Linear-выход (логиты). BinaryCrossEntropy требует Sigmoid. Mse/Mae — Linear. Нарушение пары = мёртвая сеть (пример — baseline из §1).
- MAE — для регрессии. На классификации он медленнее и нестабильнее, чем SoftmaxCE/BCE, даже если выход правильный.
- Sigmoid в скрытых слоях — почти всегда плохо. Tanh или LeakyRelu — стандарт.
- batchSize=1 + SGD — учебная демонстрация, не рабочий рецепт. Шум градиента в MAE особенно вреден.
