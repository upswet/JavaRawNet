# Глава 1. Сети с памятью. Как вообще это

Рекуррентные нейронные сети (Recurrent Neural Networks, RNN).  Память через состояние.

## Зачем нужны RNN

Обычная полносвязная сеть предполагает, что вход имеет фиксированный размер: например, 10 нейронов — значит, на вход всегда подаётся вектор длины 10. 
Но часто данные — это последовательность переменной длины:
- текст, музыка, видео - последовательность слов, нот, кадров.
- управление роботом: последовательность наблюдений и действий

Для таких данных нельзя заранее сказать: «нам нужно ровно N входных нейронов». 
Длина может быть разной, а главное — важен порядок. 
Строка 123 и 321 состоят из одних и тех же символов, но смысл разный.

>Ключевая идея RNN: сеть обрабатывает последовательность по одному элементу за раз и хранит скрытое состояние — внутреннюю память о том, что уже было обработано.

## Простейшая RNN: архитектура

- x — входной слой
- h — скрытый рекуррентный слой, который замыкается сам на себя
- y — выходной слой

```text
x[t] ─── W_xh ───┐
                 ▼
h[t-1] ─ W_hh ─► [ h[t] ] ─── W_yh ───► y[t]
                    │
                    └──► h[t] станет «прошлым состоянием» на следующем шаге
```

На каждом шаге t:
- подаётся очередной элемент последовательности x[t]
- вычисляется новое скрытое состояние h[t] с учётом x[t] и предыдущего состояния h[t-1]
- вычисляется выход y[t]
- состояние h[t] переходит на следующий шаг

```text
h[t] = f_h( W_xh · x[t] + W_hh · h[t-1] + b_h )
y[t] = f_y( W_yh · h[t] + b_y )

где:
    x[t] — входной вектор на шаге t
    h[t] — скрытое состояние на шаге t
    h[t-1] — скрытое состояние на предыдущем шаге
    y[t] — выход на шаге t (y[t] нужен не всегда: в классификации последовательности — только y[T], в seq2seq или seq-labeling — на каждом шаге.)
    W_xh — матрица весов «вход → скрытый слой»;
    W_hh — матрица рекуррентных весов «скрытый слой → скрытый слой»
    W_yh — матрица весов «скрытый слой → выход»
    b_h, b_y — смещения
    f_h, f_y — функции активации, например sigmoid или tanh

Матрицы W_xh, W_hh, W_yh не меняются от шага к шагу. 
Это называется разделением весов во времени / parameter sharing.

Начальное состояние h[0] = 0. То есть до начала (до обработки первого элемента) последовательности «память» пуста.
```

Почему функция активации tanh, а не ReLU? 
tanh ограничен [-1, 1], поэтому h[t] не растёт бесконечно при многократном применении W_hh. 
ReLU не ограничен, и в RNN это часто приводит к взрыву. sigmoid тоже ограничен, но его производная ≤ 0.25, что усиливает затухание. 
Поэтому tanh — стандарт для RNN.

Если развернуть RNN во времени, кажется, что это много разных слоёв:
```text
t=1:  x1 → h1 → y1
t=2:  x2 → h2 → y2
t=3:  x3 → h3 → y3
...
```

Но на самом деле это одна и та же сеть, просто применённая несколько раз.
Именно поэтому RNN может работать с последовательностями переменной длины.

Выход y[t] может вычисляться на каждом шаге. 
Но в задачах типа «есть ли в строке подпоследовательность 123?» нас интересует только последний выход y[T], где T — длина последовательности.

```text
x1 → h1 → y1
x2 → h2 → y2
x3 → h3 → y3
...
xT → hT → yT   ← итоговый ответ
```

## Сравнение с обычной нейросетью

Обычная трёхслойная сеть(mlp):
```text
h = f_h( W_xh · x + b_h )
y = f_y( W_yh · h + b_y )
```

RNN:
```text
h[t] = f_h( W_xh · x[t] + W_hh · h[t-1] + b_h )
y[t] = f_y( W_yh · h[t] + b_y )
```

Разница — в слагаемом W_hh · h[t-1]. Это и есть рекуррентная связь: текущее состояние зависит от предыдущего.

## Как RNN обрабатывает последовательность: текстовый пример

Пусть на вход подаётся строка "123", а сеть должна понять, что в ней есть подпоследовательность 123.

```text
Шаг 1: x = '1'
       h1 = f(W_xh · '1' + W_hh · h0 + b_h)
       h1 запоминает: «видел 1»

Шаг 2: x = '2'
       h2 = f(W_xh · '2' + W_hh · h1 + b_h)
       h2 учитывает, что раньше была 1 → «видел 12»

Шаг 3: x = '3'
       h3 = f(W_xh · '3' + W_hh · h2 + b_h)
       h3 учитывает, что раньше было 12 → «видел 123»

Выход: y3 = f(W_yh · h3 + b_y) ≈ 1
```

Если бы строка была "124", то на третьем шаге состояние не получило бы подтверждения 3, и выход был бы ближе к 0.

```text
Строка "123":
  t=1, x='1':  h[1] ≈ [1, 0, 0, 0, 0, 0]   ← нейрон 0 горит («видел 1»)
  t=2, x='2':  h[2] ≈ [0, 1, 0, 0, 0, 0]   ← нейрон 1 горит («видел 12»)
  t=3, x='3':  h[3] ≈ [0, 0, 1, 0, 0, 0]   ← нейрон 2 горит («видел 123»)
  
Строка "124":
  t=1, x='1':  h[1] ≈ [1, 0, 0, 0, 0, 0]
  t=2, x='2':  h[2] ≈ [0, 1, 0, 0, 0, 0]
  t=3, x='4':  h[3] ≈ [0, 0, 0, 0, 0, 0]   ← нейрон 2 не горит («123» не найдено)
```

        // Нейрон 1: активен, когда на входе '2' и нейрон 0 был активен на предыдущем шаге

        Whh[1][0] = 10.0;

        Whh[2][2] = 20.0;   // самоподдержка
        bh[2] = -15.0;

        // --- Детектор "789" ---

        bh[3] = -5.0;

        Wxh[4][charToIndex.get('8')] = 10.0;
        Whh[4][3] = 10.0;
        bh[4] = -15.0;

        Wxh[5][charToIndex.get('9')] = 10.0;
        Whh[5][4] = 10.0;

        Why[1][5] = 10.0;   // h5 -> выход "789"

        by[1] = -5.0;

## Backpropagation Through Time

Backpropagation Through Time, BPTT — обратное распространение ошибки во времени.
Алгоритм обучения RNN.

Обучение RNN отличается от обучения обычной сети тем, что сеть обрабатывает данные последовательно и учитывает предыдущие шаги. При расчёте ошибки последовательность разворачивается во времени — как будто сеть превращается в цепочку одинаковых слоёв. 
Ошибка от конца последовательности распространяется обратно по всей цепочке.

BPTT — это обычный backprop, только применённый к развёрнутой во времени RNN. 
Веса на всех шагах общие, поэтому градиенты по ним накапливаются по всем временным шагам.

Если развернуть RNN во времени, получится обычная сеть с T слоями, где все слои имеют общие веса. BPTT — это backprop по этой развёрнутой сети. 
Единственное отличие: градиенты по общим весам суммируются по всем шагам.

Развёртка по времени:
```text
Прямой проход:
x1 → h1 → y1
     ↓
x2 → h2 → y2
     ↓
x3 → h3 → y3
     ...
xT → hT → yT

Рекуррентная связь:
h1 ───► h2 ───► h3 ───► ... ───► hT

Обратный проход:
δh1 ◄─── δh2 ◄─── δh3 ◄─── ... ◄─── δhT
```

Ошибка на шаге t зависит не только от текущего входа, но и от всех предыдущих скрытых состояний. 
Поэтому градиент нужно «протащить» назад по времени: от последнего шага к первому.

## Алгоритм работы

Прямой проход

```text
h[0] = 0
для t = 1..T:
    z_h[t] = W_xh · x[t] + W_hh · h[t-1] + b_h
    h[t]   = f_h(z_h[t])

    z_y[t] = W_yh · h[t] + b_y
    y[t]   = f_y(z_y[t])

    сохранить x[t], h[t], z_h[t], z_y[t]

в общем случае L = сумма по t L_t(y[t], target[t])
но чаще нам нужен только финальный ответ сети L = L_T(y[T], target)

все состояния нам может потребоваться вернуть на задаче пошагового предсказания (seq-labeling) где ответ нужен на каждом шаге
```

```java
 /** <h2>Формат ввода/вывода</h2>
        * Вход  — плоский {@code float[]} длины {@code seqLen * features},
        *          {@code idx = t*features + j}.
        * Выход — плоский {@code float[]} длины:
        * <ul>
 *   <li>{@code seqLen * hidden} при {@code returnSequences == true};</li>
        *   <li>{@code hidden}            при {@code returnSequences == false}.</li>
        * </ul>*/
    @Override
    public float[] forward(float[] input, boolean training) {
        if (input.length != inputSize())
            throw new IllegalArgumentException(
                    "input.length (" + input.length + ") != inputSize() (" + inputSize() + ")");

        this.inputRef = input;
        // h_{-1} = 0 (буфер переиспользуется — обязательно очищаем)
        Arrays.fill(hCache[0], 0f);

        for (int t = 0; t < seqLen; t++) {
            float[] hPrev = hCache[t];
            float[] z     = zCache[t];
            float[] h     = hCache[t + 1];
            final int xOff = t * features;

            for (int k = 0; k < hidden; k++) {
                float s = biases[k];
                float[] w = weights[k];
                for (int j = 0; j < features; j++) s += w[j] * input[xOff + j];
                for (int j = 0; j < hidden;  j++) s += w[features + j] * hPrev[j];
                z[k] = s;
            }
            activate.apply(z, h);

            if (returnSequences) {
                System.arraycopy(h, 0, output, t * hidden, hidden);
            }
        }

        if (!returnSequences) {
            System.arraycopy(hCache[seqLen], 0, output, 0, hidden);
        }
        return output;
    }
```

Обратный проход:
```text
инициализировать градиенты:
    dW_xh = 0, dW_hh = 0, db_h = 0
    dW_yh = 0, db_y = 0

δ_next = 0   // вклад «будущего» в δ_h; для t=T+1 его нет
             // На последнем шаге t=T «будущего» нет, поэтому δ_next = 0. На шаге t=T-1 δ_next — это градиент от шага T, и т.д. Именно так ошибка «течёт» назад по времени.
для t = T..1:
    // ошибка выхода текущего шага
    δ_y = ∂L/∂y[t] ⊙ f_y'(z_y[t])

    // полный градиент по h[t]
    δ_h = W_yh^T · δ_y + δ_next

    // градиент по пред-активации скрытого слоя
    δ_pre = δ_h ⊙ f_h'(z_h[t])

    // накопление градиентов параметров
    dW_yh += δ_y · h[t]^T
    db_y  += δ_y

    dW_xh += δ_pre · x[t]^T       // Ошибка на шаге t зависит от W_xh, ошибка на шаге t+1 — тоже. Общий градиент по W_xh — это сумма градиентов от всех шагов. Это и есть «разделение весов во времени»: один вес — много вкладов в градиент.
    dW_hh += δ_pre · h[t-1]^T
    db_h  += δ_pre

    // подготовка δ_next для предыдущего шага
    δ_next = W_hh^T · δ_pre
    
    
и затем обновление праметров (обучение):
W_xh -= lr · dW_xh
W_hh -= lr · dW_hh
W_yh -= lr · dW_yh
b_h  -= lr · db_h
b_y  -= lr · db_y    
```

```java
    @Override
//Начинается обратный проход с loss.derivative(outputs, targets, outputGradient) - градиента функции потерь по выходу сети
    public float[] backward(float[] deltaNext) {
        if (deltaNext.length != outputSize())
            throw new IllegalArgumentException(
                    "deltaNext.length (" + deltaNext.length + ") != outputSize() (" + outputSize() + ")");
        if (inputRef == null)
            throw new IllegalStateException("backward вызван без предшествующего forward");

        Arrays.fill(prevDelta, 0f);
        Arrays.fill(dhNextBuffer, 0f);

        for (int t = seqLen - 1; t >= 0; t--) {
            float[] z = zCache[t];
            float[] h = hCache[t + 1];
            final boolean last = (t == seqLen - 1);
            final int dOff = returnSequences ? t * hidden : 0;

            activate.derivative(z, h, dActBuffer);

            for (int k = 0; k < hidden; k++) {
                float incoming = returnSequences
                        ? deltaNext[dOff + k]
                        : (last ? deltaNext[k] : 0f);
                dzBuffer[k] = (incoming + dhNextBuffer[k]) * dActBuffer[k];
            }

            float[] hPrev = hCache[t];
            final int xOff = t * features;

            for (int k = 0; k < hidden; k++) {
                float dz = dzBuffer[k];
                biasGrad[k] += dz;
                float[] wg = weightGrad[k];
                for (int j = 0; j < features; j++) wg[j]            += dz * inputRef[xOff + j];
                for (int j = 0; j < hidden;   j++) wg[features + j] += dz * hPrev[j];
            }

            // dx_t = Wxᵀ · dz
            for (int j = 0; j < features; j++) {
                float s = 0f;
                for (int k = 0; k < hidden; k++) s += weights[k][j] * dzBuffer[k];
                prevDelta[xOff + j] = s;
            }

            // dh_next = Whᵀ · dz — через временный буфер + swap,
            // чтобы не затереть dhNextBuffer, читаемый на шаге t-1.
            for (int j = 0; j < hidden; j++) {
                float s = 0f;
                for (int k = 0; k < hidden; k++) s += weights[k][features + j] * dzBuffer[k];
                dhNextTmp[j] = s;
            }
            float[] swap = dhNextBuffer;
            dhNextBuffer = dhNextTmp;
            dhNextTmp    = swap;
        }
        return prevDelta;
    }
```

- Прямой проход сохраняет все промежуточные состояния: x[t], h[t], z_h[t], z_y[t].
- Потеря суммирует ошибки по шагам, если выход нужен на каждом шаге. Если нужен только финальный ответ — можно брать только последний выход.
- Обратный проход начинается с конца. Сначала считаем ошибку на последнем выходе, затем движемся назад по времени.
- δ_next — это «будущий» вклад в градиент по скрытому состоянию. Именно через него ошибка течёт от будущих шагов к прошлым.
- Градиенты по весам накапливаются по всем шагам, потому что веса общие.
- Рекуррентная связь заставляет ошибку течь от будущего к прошлому.

## Главная проблема BPTT: затухающие и взрывающиеся градиенты

При многократном умножении на W_hh градиент может стать очень маленьким или очень большим.
$$
δh_t \approx (W_hh^T)^(T-t) · ...
$$
>Примерно равно (пропорционально): точная формула включает производные активаций, но главный множитель — это (W_hh^T)^(T-t). Если W_hh имеет собственные числа < 1, градиент затухает экспоненциально; если > 1 — взрывается.

- RNN постепенно «забывает», что было в начале;
- влияние первого элемента к концу последовательности становится совсем маленьким;
- сеть плохо учится на длинных зависимостях;
- это называют проблемой кратковременной памяти и проблемой исчезающего градиента.

Численный пример затухания градиента
```text
Если W_hh имеет собственное число 0.9:
  T-t = 10:  0.9^10  ≈ 0.35
  T-t = 50:  0.9^50  ≈ 0.005
  T-t = 100: 0.9^100 ≈ 0.00003

То есть через 50 шагов градиент от первого элемента уменьшается в 200 раз.
Сеть «не слышит» начало последовательности.
```

Для борьбы со взрывом градиентов применяют gradient clipping — отсечение градиентов. 

Для борьбы с затуханием в следующих главах изучают LSTM и GRU.

## Bidirectional RNN - смотреть в обе стороны

Обычная RNN читает последовательность слева направо. Но иногда важен и правый контекст.

Пример: строка "12x34y789z". Чтобы понять, что там есть 789, сети нужно дойти до конца. При этом левый контекст может уже «забыться».

Bidirectional RNN обрабатывает последовательность в двух направлениях:

```text
        ┌──────────────► прямой слой ──────────────┐
x[1..T] ┤                                          ├─► concat ─► Dense ─► y
        └──────────────► обратный слой ◄───────────┘
```

BidirectionalRNN:
- внутри держать два SimpleRNNLayer — прямой и обратный;
- конкатенировать их выходы;

> Выходы двух слоёв конкатенируются по оси признаков: если прямой слой даёт hidden, обратный тоже hidden, то общий выход — 2·hidden. 
> Для returnSequences=false один вектор 2·hidden; для true множество векторов(уложенных в один большой, плоский вектор) seqLen × 2·hidden.
