# Нейросети. Практический учебник для java-разработчиков
(версия 1.0. От 11.2026-го)

>Нахрен вам Хогвартс, если есть машинное обучение ?!

Таков путь:
1. MLP — предсказывает
2. CNN — видит
3. RNN — помнит (память через состояние)
4. Transformer — связывает (память через адресацию)
5. RL — действует

Такие вопросы:
1. Можно ли предсказать ответ по признакам?
2. Можно ли использовать пространство?
3. Можно ли использовать порядок и время?
4. Можно ли использовать длинный контекст?
5. Можно ли научиться действовать без учителя?

Примеры и весь код в документе приводится на java а не ставшем фактически стандарте в ML python-е просто потому, что я так хочу.

Но, если серьёзно, то питон слишком высокоуровневый язык (знаете шутку, что когда питон-программисту надо решить задачу он просто ищет подходящую библиотеку решающую задачу?), а нам здесь требуется разбираться с алгоритмами на низком уровне.

Я написал этот учебник (и библиотеку к нему) для таких как я сам - опытных джава-разработчиков порядком забывших институтскую математику, но не разучившимся удивляться тому чуду, которым неожиданно для всех стали большие языковые модели.
Для тех, кто хотел бы стать частью чуда. Нормального учебника не нашлось. Пришлось написать его самому.

Требуемый уровень для использования данного учебника
- Очень желательно знание языка программирования java и библиотеки сокращения объёма написанного кода lombok. Впрочем, вы всегда можете попросить ИИ-шку расталковать вам приведённый код и переложить его на любой другой язык программирования по вашему выбору. Да, будущее наступило - пользуйтесь его возможностями.
- В идеале требуется знание математического анализа (логарифмы, производные, градиенты) и линейной алгебры (матрицы, вектора, операции над ними) в пределах 1 (максимум 2-го) курса института. Но если вы всё давно забыли, то не страшно. Чтобы освежить память, обратитесь к соответствующему приложению данного учебника.

Если всё совсем плохо и материал кажется вам слишком сложным, то рекомендую сначала обратиться к книге "Создаем нейронную сеть" Тарика Рашида.
А после полирнуть книгой "Грокаем глубокое обучение" Эндрю Траск-а.

В добрый путь, друзья.
