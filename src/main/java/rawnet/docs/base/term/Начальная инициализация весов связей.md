# Начальная инициализация весов связей

Можно, конечно, сделать просто небольшое число вида 
```java
float weight = (float) (Math.random() * 0.2f - 0.1f); //вес связи
```
и предоставить дальнейшее алгоритму.

Но правильное распределение залог более быстрой сходимости.

>Представьте сеть из 10 слоёв с активацией tanh. 
> Если инициализировать веса стандартно N(0, 1), то дисперсия сигнала на выходе будет расти как (fan_in)^L — уже на 10-м слое сигнал улетит в миллионы, tanh насытится, градиент станет нулём. 
> Если наоборот, веса слишком маленькие — сигнал затухнет до 1e-10, и обучение не сдвинется с места. 
> Задача инициализации — подобрать масштаб так, чтобы дисперсия не менялась от слоя к слою.

## Xavier/Glorot инициализация
Это способ правильно задать начальные веса нейросети. Её главное преимущество: она сохраняет примерно одинаковый масштаб сигнала и градиента во всех слоях, поэтому сеть не страдает от затухающих или взрывающихся градиентов.

Xavier подбирает масштаб весов так, чтобы дисперсия сигнала при прямом проходе и дисперсия градиента при обратном проходе оставались примерно постоянными от слоя к слою.

Xavier лучше всего работает с симметричными активациями: tanh, sigmoid, линейными.

>Откуда берётся формула √(6/(fan_in+fan_out))
> 
>Пусть вход x имеет дисперсию Var(x), веса w — дисперсию Var(w), и они независимы. 
> Тогда выход y = Σ wᵢxᵢ имеет дисперсию fan_in · Var(w) · Var(x). Чтобы Var(y) = Var(x), нужно Var(w) = 1/fan_in. 
> Аналогично для обратного прохода получаем Var(w) = 1/fan_out. 
> Компромисс между этими двумя требованиями — Var(w) = 2/(fan_in + fan_out). 
> Для равномерного распределения на [-a, a] дисперсия равна a²/3, откуда a = √(6/(fan_in+fan_out)).

## He/Kaiming

Используется обычно для ReLU и её производных.

> Xavier делит на fan_in + fan_out — «симметрично» смотрит в обе стороны, потому что sigmoid/tanh симметричны относительно нуля. 
> He делит только на fan_in и добавляет множитель 2 — потому что ReLU «выключает» половину нейронов, и дисперсия на выходе падает вдвое; множитель 2 это компенсирует.


```java
    /**
 * Хелпер выбора предела равномерной инициализации весов по типу
 * активации: Xavier/Glorot — для Sigmoid/Tanh/Linear, He/Kaiming —
 * для LeakyReLU, маленькое число — для остальных.
 */
private static float initLimit(Activate activate, int fanIn, int fanOut) {
    if (activate instanceof Sigmoid || activate instanceof Tanh || activate instanceof Linear)
        return (float) Math.sqrt(6.0 / (fanIn + fanOut));
    if (activate instanceof LeakyRelu)
        return (float) Math.sqrt(6.0 / fanIn);
    return 0.1f;
}

public DenseLayer(int inputSize, int outputSize, Activate activate) {
    ...

    // Инициализация весов по типу активации.
    float limit = initLimit(activate, inputSize, outputSize);

    Random rnd = ThreadLocalRandom.current();
    for (int i = 0; i < outputSize; i++) {
        for (int j = 0; j < inputSize; j++) {
            weights[i][j] = rnd.nextFloat() * 2 * limit - limit;
        }
        biases[i] = rnd.nextFloat() * 0.2f - 0.1f;
    }
}
```

Cовременные сети часто живут с инициализацией „как получится“, потому что нормализация между слоями (BatchNorm/LayerNorm) сама выравнивает масштаб.
