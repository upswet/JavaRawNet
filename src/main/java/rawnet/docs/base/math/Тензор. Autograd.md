# Autograd

**Autograd (автоматическое дифференцирование)**— это механизм, который автоматически вычисляет производные сложной функции по её входным параметрам.

Если у вас есть функция `loss = f(x, w)`, и вы хотите обновить w так, чтобы loss уменьшился (градиентный спуск), вам нужны $\partial loss/\partial w$.
Autograd делает это за вас, не требуя писать формулы производных вручную.

Два ключевых понятия:
- Forward — обычное вычисление (`y = x.matmul(w).relu().sum()`).
- Backward — обратный проход: начиная с $\partial loss/\partial loss = 1$, идём по графу операций в обратном порядке и по цепному правилу получаем $\partial loss/\partial x$, $\partial loss/\partial w$.

```text
dL/dL = 1
В обратном распространении (backpropagation) это — стартовая точка. 
Ты начинаешь с того, что «градиент по самой функции потерь» равен 1, а потом цепным правилом спускаешься ниже по слоям.

Пример цепочки:

На выходе сети у тебя есть loss L.
Он зависит от выхода последнего слоя y: L=L(y).
Тогда по цепному правилу:  dL/dy = dL/dL * dL/dy = 1 * dL/dy

dL/dL = 1 формально фиксирует: «мы начинаем обратное распространение с единицы», и дальше умножаем на производные по промежуточным переменным.
```

Чтобы backward работал, нужно:
- Запомнить граф — какие операции были и с какими входами.
- Для каждой операции знать её локальную производную — $\partial y/\partial x$ и $\partial y/\partial w$.
- Уметь накапливать градиенты — если x используется в двух местах, вклады складываются.

Отсюда сразу следуют два практических свойства, которые полезно держать в голове:
- Память. Граф хранит промежуточные активации — они нужны для backward.
  Поэтому память под обучение заметно больше, чем под инференс.
- Точка отсчёта. Backward запускается только от скаляра (обычно loss).
  Если у вас тензор из нескольких элементов, стартовый градиент — тензор из единиц.

## Пример1. Скалярный autograd

Самое простое, что вообще может называться autograd — скалярное значение с поддержкой градиента

```java
import java.util.ArrayList;
import java.util.List;
import java.util.function.Consumer;

/**
 * Скалярное значение с поддержкой autograd.
 *
 * <p>Каждый {@code Scalar} хранит:
 * <ul>
 *   <li>{@code data} — само число;</li>
 *   <li>{@code grad} — накопленный градиент (∂loss/∂this);</li>
 *   <li>{@code backward} — замыкание, которое «раздаёт» градиент своим входам.</li>
 * </ul>
 *
 * <p>Это упрощённая модель: тензор здесь — скаляр. Но все принципы
 * autograd видны уже на нём.
 */
public class Scalar {
    public float data;
    public float grad;
    private final List<Scalar> inputs;      // от кого мы зависим
    private final Consumer<Float> backward; // как раздать градиент входам

    public Scalar(float data) {
        this.data = data;
        this.grad = 0f;
        this.inputs = List.of();
        this.backward = g -> {
        };           // листья графа ничего не раздают
    }

    private Scalar(float data, List<Scalar> inputs, Consumer<Float> backward) {
        this.data = data;
        this.grad = 0f;
        this.inputs = inputs;
        this.backward = backward;
    }

    // ---------- операции ----------

    public Scalar add(Scalar other) {
        // d(a+b)/da = da/da + db/da = 1 + 0 = 1 
        // d(a+b)/db = 1
        return new Scalar(data + other.data,
                List.of(this, other),
                g -> {
                    this.grad += g;
                    other.grad += g;
                });
    }

    public Scalar mul(Scalar other) {
        // d(a*b)/da = b, так как b-константа по сравнению с da 
        // d(a*b)/db = a
        return new Scalar(data * other.data,
                List.of(this, other),
                g -> {
                    this.grad += g * other.data;
                    other.grad += g * this.data;
                });
    }

    public Scalar sub(Scalar other) {
        return new Scalar(data - other.data,
                List.of(this, other),
                g -> {
                    this.grad += g;
                    other.grad -= g;
                });
    }

    public Scalar div(Scalar other) {
        // d(a/b)/da = 1/b, аналогично, только здесь константа 1/b
        // d(a/b)/db = -a/b²
        return new Scalar(data / other.data,
                List.of(this, other),
                g -> {
                    this.grad += g / other.data;
                    other.grad -= g * data / (other.data * other.data);
                });
    }

    public Scalar relu() {
        // d(relu(x))/dx = x > 0 ? 1 : 0
        //ReLU(то есть f(x) = max(0, x)) пропускает градиент только для положительных входов.
        return new Scalar(Math.max(0f, data),
                List.of(this),
                g -> {
                    if (data > 0) this.grad += g;
                });
    }

    public Scalar tanh() {
        float t = (float) Math.tanh(data);
        // d(tanh(x))/dx = 1 - tanh²(x)
        return new Scalar(t,
                List.of(this),
                g -> {
                    this.grad += g * (1 - t * t);
                });
    }

    // ---------- backward ----------

    /**
     * Обратный проход: топологическая сортировка + reverse traversal.
     *
     * <p>Алгоритм:
     * <ol>
     *   <li>Обходим граф в глубину, собираем все узлы в порядке пост-визита.</li>
     *   <li>Идём по списку в обратном порядке: для каждого узла вызываем
     *       {@code backward.accept(node.grad)}, что раскидывает градиент входам.</li>
     * </ol>
     *
     * <p>Стартовое условие: {@code this.grad = 1}, потому что ∂this/∂this = 1.
     */
    public void backward() {
        List<Scalar> topo = new ArrayList<>();
        topoSort(this, topo);
        this.grad = 1f;
        for (int i = topo.size() - 1; i >= 0; i--) {
            Scalar v = topo.get(i);
            v.backward.accept(v.grad);
        }
    }

    private static void topoSort(Scalar v, List<Scalar> out) {
        // простая рекурсия без отметки visited — граф маленький и без циклов
        for (Scalar in : v.inputs) topoSort(in, out);
        out.add(v);
    }

    /** Обнуляет градиенты всех узлов графа. Нужно вызывать перед каждым backward. */
    public void zeroGrad() {
        List<Scalar> topo = new ArrayList<>();
        topoSort(this, topo);
        for (Scalar v : topo) v.grad = 0f;
    }

    @Override
    public String toString() {
        return String.format("Scalar(%.4f, grad=%.4f)", data, grad);
    }

    public static void main(String[] args) {
        Scalar x = new Scalar(2.0f);
        Scalar w = new Scalar(3.0f);
        Scalar b = new Scalar(-1.0f);

        Scalar y = x.mul(w).add(b).relu(); // f(x,w,b) = relu(x*w + b)
        System.out.println("y = " + y);   // y.data = relu(5) = 5

        y.backward();
        System.out.println("dy/dx = " + x.grad);  // w = 3
        System.out.println("dy/dw = " + w.grad);  // x = 2
        System.out.println("dy/db = " + b.grad);  // 1
    }
}
```
- backward — это замыкание, которое знает, как раздать градиент. Оно запоминает локальные значения (other.data, data) на момент forward.
- Градиенты накапливаются через +=, а не присваиваются. Это позволяет корректно обрабатывать ветвления: если x используется дважды, оба вклада сложатся.
- Топологическая сортировка гарантирует, что узел обрабатывается только после того, как все его «потомки» раздали градиент.
- zeroGrad обязателен перед каждым backward в цикле обучения — иначе градиенты копятся итерация за итерацией.

*Замечание про переполнение стека. Рекурсивный topoSort в скалярной версии упадёт на глубоких графах (типичная сеть — десятки тысяч узлов). В реальных библиотеках обход делают итеративно (явный стек)*

### Пример2. Тензорный autograd: только базовые операции

Что меняется при переходе к тензору
- grad — это тоже тензор: плоский float[] той же формы, что data, в row-major layout (contiguous — backward-функции пишут в него напрямую).
- Backward-замыкание не получает g параметром, а читает res.grad результата: к моменту его вызова (обратный топологический порядок) градиент узла уже собран полностью.
- Появляется unbroadcast — обратная операция к broadcasting: градиент «сжимается» обратно к форме входа суммированием по растянутым осям.
- requiresGrad у результата = OR по входам: если ни один вход не обучаемый, подграф не участвует в backward.

Расширяем Tensor
```java
private float[] grad;              // градиент той же формы, что data (ленивый)
private Runnable backwardFn;       // раздаёт grad входам (как раздать градиент родителям)
private Tensor[] inputs;           // от кого зависим (родители в графе)
private boolean requiresGrad;      // нужно ли считать градиент по этому тензору
```

```java
import java.util.*;

/**
 * Минимальный тензор с поддержкой autograd.
 *
 * <p>Поддерживаются только базовые операции:
 * поэлементные add/mul, matmul, transpose, relu, sum.
 *
 * <p>Формы для add/mul должны совпадать. Broadcasting намеренно
 * опущен, чтобы код остался компактным.
 */
public class Tensor {
    public float[] data;
    public float[] grad;
    private final int[] shape;
    private Tensor[] inputs;
    private Runnable backwardFn;
    private boolean requiresGrad;

    /**
     * Создаёт лист графа — тензор без родителей.
     *
     * @param data  значения тензора
     * @param shape размеры; произведение должно совпадать с data.length
     */
    public Tensor(float[] data, int... shape) {
        if (size(shape) != data.length) {
            throw new IllegalArgumentException("shape не соответствует data.length");
        }
        this.data = data;
        this.shape = shape.clone();
        this.grad = new float[data.length];
        this.inputs = new Tensor[0];
        this.backwardFn = () -> {};
        this.requiresGrad = false;
    }

    /**
     * Внутренний конструктор для узлов-операций.
     *
     * @param data         значения результата
     * @param shape        форма результата
     * @param inputs       родители в графе
     * @param requiresGrad нужно ли считать градиент
     */
    private Tensor(float[] data, int[] shape, Tensor[] inputs, boolean requiresGrad) {
        this.data = data;
        this.shape = shape.clone();
        this.grad = new float[data.length];
        this.inputs = inputs != null ? inputs : new Tensor[0];
        this.backwardFn = () -> {};
        this.requiresGrad = requiresGrad;
    }

    /**
     * Создаёт тензор из массива и формы.
     */
    public static Tensor of(float[] data, int... shape) {
        return new Tensor(data, shape);
    }

    /**
     * Создаёт тензор из нулей заданной формы.
     */
    public static Tensor zeros(int... shape) {
        return new Tensor(new float[size(shape)], shape);
    }

    /**
     * Создаёт скалярный тензор формы [1].
     */
    public static Tensor scalar(float value) {
        return new Tensor(new float[]{value}, 1);
    }

    /**
     * Возвращает число элементов.
     */
    public int size() {
        return data.length;
    }

    /**
     * Возвращает копию формы.
     */
    public int[] shape() {
        return shape.clone();
    }

    /**
     * Включает или выключает вычисление градиента для этого тензора.
     * Обычно вызывается для листьев — например, весов.
     */
    public Tensor setRequiresGrad(boolean value) {
        this.requiresGrad = value;
        return this;
    }

    /**
     * Нужно ли считать градиент по этому тензору.
     */
    public boolean requiresGrad() {
        return requiresGrad;
    }

    /**
     * Поэлементное сложение. Формы должны совпадать.
     *
     * <p>Backward: градиент выхода просто раздаётся обоим входам.
     */
    public Tensor add(Tensor other) {
        checkSameShape(this, other);
        Tensor out = new Tensor(new float[data.length], shape,
                new Tensor[]{this, other},
                requiresGrad || other.requiresGrad);

        for (int i = 0; i < data.length; i++) {
            out.data[i] = data[i] + other.data[i];
        }

        out.backwardFn = () -> {
            for (int i = 0; i < out.grad.length; i++) {
                this.grad[i] += out.grad[i];
                other.grad[i] += out.grad[i];
            }
        };

        return out;
    }

    /**
     * Поэлементное умножение. Формы должны совпадать.
     *
     * <p>Backward: d(a*b)/da = b, d(a*b)/db = a.
     */
    public Tensor mul(Tensor other) {
        checkSameShape(this, other);
        Tensor out = new Tensor(new float[data.length], shape,
                new Tensor[]{this, other},
                requiresGrad || other.requiresGrad);

        for (int i = 0; i < data.length; i++) {
            out.data[i] = data[i] * other.data[i];
        }

        out.backwardFn = () -> {
            for (int i = 0; i < out.grad.length; i++) {
                this.grad[i] += out.grad[i] * other.data[i];
                other.grad[i] += out.grad[i] * this.data[i];
            }
        };

        return out;
    }

    /**
     * Матричное умножение 2D-тензоров: [N,K] x [K,M] -> [N,M].
     *
     * <p>Backward:
     * gradA = gradY * B^T,
     * gradB = A^T * gradY.
     */
    public Tensor matmul(Tensor other) {
        if (shape.length != 2 || other.shape.length != 2) {
            throw new IllegalArgumentException("matmul поддерживает только 2D тензоры");
        }

        int N = shape[0], K = shape[1];
        int K2 = other.shape[0], M = other.shape[1];

        if (K != K2) {
            throw new IllegalArgumentException("Несовместимые формы для matmul");
        }

        Tensor out = new Tensor(new float[N * M], new int[]{N, M},
                new Tensor[]{this, other},
                requiresGrad || other.requiresGrad);

        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                float sum = 0f;
                for (int k = 0; k < K; k++) {
                    sum += data[i * K + k] * other.data[k * M + j];
                }
                out.data[i * M + j] = sum;
            }
        }

        out.backwardFn = () -> {
            for (int i = 0; i < N; i++) {
                for (int j = 0; j < M; j++) {
                    float g = out.grad[i * M + j];
                    for (int k = 0; k < K; k++) {
                        this.grad[i * K + k] += g * other.data[k * M + j];
                        other.grad[k * M + j] += g * data[i * K + k];
                    }
                }
            }
        };

        return out;
    }

    /**
     * Транспонирование 2D-тензора.
     *
     * <p>Backward: градиент транспонируется обратно.
     */
    public Tensor transpose() {
        if (shape.length != 2) {
            throw new IllegalArgumentException("transpose поддерживает только 2D тензоры");
        }

        int rows = shape[0], cols = shape[1];
        Tensor out = new Tensor(new float[data.length], new int[]{cols, rows},
                new Tensor[]{this},
                requiresGrad);

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                out.data[j * rows + i] = data[i * cols + j];
            }
        }

        out.backwardFn = () -> {
            for (int i = 0; i < rows; i++) {
                for (int j = 0; j < cols; j++) {
                    this.grad[i * cols + j] += out.grad[j * rows + i];
                }
            }
        };

        return out;
    }

    /**
     * ReLU: max(0, x).
     *
     * <p>Backward: пропускает градиент только там, где вход был > 0.
     */
    public Tensor relu() {
        Tensor out = new Tensor(new float[data.length], shape,
                new Tensor[]{this},
                requiresGrad);

        for (int i = 0; i < data.length; i++) {
            out.data[i] = Math.max(0f, data[i]);
        }

        out.backwardFn = () -> {
            for (int i = 0; i < data.length; i++) {
                if (data[i] > 0) {
                    this.grad[i] += out.grad[i];
                }
            }
        };

        return out;
    }

    /**
     * Сумма всех элементов. Результат — скаляр формы [1].
     *
     * <p>Backward: каждый элемент получает градиент выхода.
     */
    public Tensor sum() {
        Tensor out = new Tensor(new float[]{0f}, new int[]{1},
                new Tensor[]{this},
                requiresGrad);

        float s = 0f;
        for (float v : data) {
            s += v;
        }
        out.data[0] = s;

        out.backwardFn = () -> {
            for (int i = 0; i < data.length; i++) {
                this.grad[i] += out.grad[0];
            }
        };

        return out;
    }

    /**
     * Запускает обратный проход от этого тензора.
     *
     * <p>Обычно вызывается на скалярном loss. Если элементов больше одного,
     * стартовый градиент заполняется единицами.
     */
    public void backward() {
        List<Tensor> topo = new ArrayList<>();
        topoSort(this, new HashSet<>(), topo);

        if (size() == 1) {
            grad[0] = 1f;
        } else {
            Arrays.fill(grad, 1f);
        }

        for (int i = topo.size() - 1; i >= 0; i--) {
            topo.get(i).backwardFn.run();
        }
    }

    /**
     * Обнуляет градиенты всех узлов, достижимых из этого тензора.
     * Нужно вызывать перед каждым новым backward в цикле обучения.
     */
    public void zeroGrad() {
        List<Tensor> topo = new ArrayList<>();
        topoSort(this, new HashSet<>(), topo);
        for (Tensor t : topo) {
            Arrays.fill(t.grad, 0f);
        }
    }

    /**
     * Топологическая сортировка графа.
     *
     * <p>visited нужен, чтобы не обрабатывать общий узел несколько раз.
     * Без него градиенты в DAG могли бы размазаться неверно.
     */
    private static void topoSort(Tensor v, Set<Tensor> visited, List<Tensor> out) {
        if (!visited.add(v)) return;
        for (Tensor in : v.inputs) {
            topoSort(in, visited, out);
        }
        out.add(v);
    }

    /**
     * Проверяет, что формы совпадают.
     */
    private static void checkSameShape(Tensor a, Tensor b) {
        if (!Arrays.equals(a.shape, b.shape)) {
            throw new IllegalArgumentException(
                    "Формы не совпадают: " + Arrays.toString(a.shape) +
                            " vs " + Arrays.toString(b.shape));
        }
    }

    /**
     * Вычисляет произведение размеров формы.
     */
    private static int size(int[] shape) {
        int s = 1;
        for (int d : shape) s *= d;
        return s;
    }

    @Override
    public String toString() {
        return "Tensor(shape=" + Arrays.toString(shape) +
                ", data=" + Arrays.toString(data) +
                ", grad=" + Arrays.toString(grad) + ")";
    }

    /**
     * Небольшой пример: f(x,w,b) = sum(relu(x*w + b)).
     */
    public static void main(String[] args) {
        Tensor x = Tensor.of(new float[]{2f}, 1).setRequiresGrad(true);
        Tensor w = Tensor.of(new float[]{3f}, 1).setRequiresGrad(true);
        Tensor b = Tensor.of(new float[]{-1f}, 1).setRequiresGrad(true);

        Tensor y = x.mul(w).add(b).relu().sum();
        y.backward();

        System.out.println("y = " + y.data[0]);        // 5
        System.out.println("dy/dx = " + x.grad[0]);    // 3
        System.out.println("dy/dw = " + w.grad[0]);    // 2
        System.out.println("dy/db = " + b.grad[0]);    // 1
    }
}
```

В версии для Scalar visited не было — там граф считался деревом.
В тензорной версии граф — это DAG: один и тот же узел может иметь несколько «потребителей».
Без visited такой узел добавился бы в топологический порядок несколько раз, и backwardFn вызвался бы повторно — градиенты задвоились бы.

```text
В скалярном случае 
    y = a + b
    dL/da = dL/dy * dy/da
    
В тензорном случае
    Y = A + B (тензоры)
    dLoss/dA = dLoss/dY * ∂Y/∂A 
    
Для поэлементного сложения производная по каждому входу это просто «единицы» в тех позициях, где вход участвовал.  
Поэтому локальная производная ∂Y/∂A это тензор из единиц той же формы, что и Y.      

Если A и B имели разные формы, но сложились через broadcasting (например, A — [3, 4], B — [1, 4]), то Y будет [3, 4]. Локальная производная формально [3, 4], но нам нужно получить градиент по A, который тоже [3, 4] — тут всё совпадает.

А вот градиент по B (форма [1, 4]) нужно агрегировать по тем осям, которые были «растянуты» при broadcasting. В примере выше это ось 0: все строки Y использовали одну и ту же строку B, поэтому градиенты по этим строкам нужно просуммировать, чтобы получить градиент для B. 
```
```text
Для y = a * b (element-wise):
∂y/∂a = grad_y * b (по правилу произведения).
∂y/∂b = grad_y * a.

Tensor gradA = gradY.mul(B); // поэлементно
Tensor gradB = gradY.mul(A);
```

```text
Для y = a.matmul(b)
Это уже матричное умножение, и тут работает линейная алгебра, а не поэлементные правила.
Пусть:

A имеет форму [N, K]
B имеет форму [K, M]
Тогда Y=AB имеет форму [N, M]

Tensor gradA = gradY.matmul(B.transpose())
Tensor gradB = A.transpose().matmul(gradY)
```

### Пример 3. Добавить Unbroadcasting

Ключевая идея unbroadcast: forward растянул вход копированием — значит, при backward все копии «схватили» свой кусок градиента, и их нужно просуммировать обратно в одну ячейку.

Без него нельзя писать нормальные слои: x @ W + b — это буквально первый же пример, где b имеет форму [M], а x @ W — [N, M].
Сейчас ваш add такое просто отвергнет.

Идея простая:
- Forward: если формы разные, но совместимы по broadcasting-правилам NumPy — расширяем.
- Backward: для каждого входа «сжимаем» градиент обратно к его исходной форме, суммируя по осям, которые были растянуты.

```java
/**
 * Складывает тензоры с поддержкой broadcasting по правилам NumPy.
 *
 * <p>Формы выравниваются справа. Оси, где у одного из тензоров размер 1,
 * растягиваются до размера другого.
 *
 * <p>Backward: градиент выхода раздаётся обоим входам, но перед этим
 * приводится к их исходной форме через unbroadcast.
 */
public Tensor add(Tensor other) {
    int[] outShape = broadcastShape(shape, other.shape);
    Tensor out = new Tensor(new float[size(outShape)], outShape,
            new Tensor[]{this, other},
            requiresGrad || other.requiresGrad);

    // forward: перебор по outShape, индексы в a и b считаются по модулю их размеров
    int[] idx = new int[outShape.length];
    int[] aIdx = new int[outShape.length];
    int[] bIdx = new int[outShape.length];
    for (int i = 0; i < out.data.length; i++) {
        unflatten(i, outShape, idx);
        project(idx, shape, aIdx);
        project(idx, other.shape, bIdx);
        out.data[i] = data[flatten(aIdx, shape)] + other.data[flatten(bIdx, other.shape)];
    }

    out.backwardFn = () -> {
        // grad для this: раздать и потом сжать обратно к shape
        float[] gA = new float[out.data.length];
        float[] gB = new float[out.data.length];
        for (int i = 0; i < out.data.length; i++) {
            unflatten(i, outShape, idx);
            project(idx, shape, aIdx);
            project(idx, other.shape, bIdx);
            gA[i] = out.grad[i];
            gB[i] = out.grad[i];
        }
        accumulateUnbroadcast(gA, outShape, this.grad, shape);
        accumulateUnbroadcast(gB, outShape, other.grad, other.shape);
    };

    return out;
}


/**
 * Сжимает градиент формы fromShape к форме toShape, суммируя
 * по осям, которые были растянуты при broadcasting.
 *
 * <p>Пример: gradGrad формы [3,4] -> toShape [1,4] — суммируем по оси 0.
 */
private static void accumulateUnbroadcast(float[] src, int[] fromShape, float[] dst, int[] toShape) {
    int[] idx = new int[fromShape.length];
    int[] dstIdx = new int[toShape.length];
    for (int i = 0; i < src.length; i++) {
        unflatten(i, fromShape, idx);
        project(idx, toShape, dstIdx);   // "схлопываем" растянутые оси в 0
        dst[flatten(dstIdx, toShape)] += src[i];
    }
}

/**
 * Вычисляет форму результата broadcasting двух форм по правилам NumPy.
 *
 * <p>Формы выравниваются справа. Для каждой оси:
 * <ul>
 *   <li>если размеры совпадают — берём его;</li>
 *   <li>если один из них 1 — берём другой (эта ось будет «растянута»);</li>
 *   <li>иначе формы несовместимы.</li>
 * </ul>
 *
 * <p>Пример: {@code [3,1,4]} и {@code [2,4]} -> {@code [3,2,4]}.
 */
private static int[] broadcastShape(int[] a, int[] b) {
    int n = Math.max(a.length, b.length);
    int[] out = new int[n];
    for (int i = 0; i < n; i++) {
        int ai = i < n - a.length ? 1 : a[i - (n - a.length)];
        int bi = i < n - b.length ? 1 : b[i - (n - b.length)];
        if (ai == bi) {
            out[i] = ai;
        } else if (ai == 1) {
            out[i] = bi;
        } else if (bi == 1) {
            out[i] = ai;
        } else {
            throw new IllegalArgumentException(
                    "Формы несовместимы для broadcasting: "
                            + Arrays.toString(a) + " и " + Arrays.toString(b));
        }
    }
    return out;
}

/**
 * Переводит многомерный индекс в плоский (row-major).
 */
private static int flatten(int[] idx, int[] shape) {
    int off = 0;
    for (int i = 0; i < shape.length; i++) {
        off = off * shape[i] + idx[i];
    }
    return off;
}

/**
 * Обратная операция: плоский индекс -> многомерный, записывается в {@code out}.
 * {@code out.length} должен совпадать с {@code shape.length}.
 */
private static void unflatten(int flat, int[] shape, int[] out) {
    for (int i = shape.length - 1; i >= 0; i--) {
        out[i] = flat % shape[i];
        flat /= shape[i];
    }
}

/**
 * «Проецирует» индекс из более широкой формы в более узкую.
 *
 * <p>Используется в двух местах:
 * <ul>
 *   <li>forward: из индекса результата получить индекс входа.
 *       Если у входа ось была растянута (размер 1), берём индекс 0;</li>
 *   <li>backward: перебирая выходные позиции, получить целевую позицию
 *       входа. Все растянутые позиции «схлопываются» в один и тот же
 *       целевой индекс, поэтому накопление через {@code +=} корректно
 *       суммирует вклады.</li>
 * </ul>
 *
 * <p>Формы выравниваются справа; «лишние» ведущие оси {@code fullIdx}
 * игнорируются (они всегда растянуты при broadcasting).
 */
private static void project(int[] fullIdx, int[] targetShape, int[] out) {
    int offset = fullIdx.length - targetShape.length;
    for (int k = 0; k < targetShape.length; k++) {
        if (targetShape[k] == 1) {
            out[k] = 0;
        } else {
            out[k] = fullIdx[offset + k];
        }
    }
}
//project делает ровно то, что нужно: если по какой-то оси в fromShape размер больше, чем в toShape (то есть там было 1), она берёт индекс 0; иначе — тот же индекс.
```

#### Правило цепочки

Если $y = f(g(x))$, то:

```text
dy/dx = dy/dg * dg/dx

```
В терминах графа: чтобы найти производную выхода по входу, нужно перемножить локальные производные вдоль пути.


Для функции многих переменных $L = f(x, y, z)$:
```text
dL/dx = dL/df * df/dx
dL/dy = dL/df * df/dy
dL/dz = dL/df * df/dz
```

Здесь $dL/df$ — это «градиент, пришедший сверху», а $df/dx$ — локальная производная операции.

### Граф вычислений

Прежде чем разбирать формулы, полезно понять, на чём работает backpropagation. Нейросеть удобно представлять как вычислительный граф:
- узлы графа — это операции (сложение, умножение, применение активации, вычисление потерь);
- рёбра — это тензоры (числа, векторы, матрицы), которые текут между операциями;
- прямой проход (forward) вычисляет выход слева направо: от входа x через слои к потере L. При этом промежуточные значения (например, $z^{(l)}$, $a^{(l)}$ сохраняются — они понадобятся при обратном проходе;
- обратный проход (backward) идёт справа налево: от L к входам. На каждом узле мы умножаем пришедший «сверху» градиент на локальную производную этой операции и передаём результат «вниз» — предыдущим узлам.

Именно это и есть динамическое программирование в действии: каждое промежуточное значение и каждая локальная производная вычисляются один раз и переиспользуются. Без графа пришлось бы заново считать одни и те же производные для каждого параметра.

---

Пример 1

```python
a = Tensor(2.0, requires_grad=True)
b = Tensor(3.0, requires_grad=True)
c = a * b
d = c + a
d.backward()
print(a.grad)  # 4.0 = b + 1
print(b.grad)  # 2.0 = a
```
```text
    a       b
     \     /
      \   /
       mul
        |
        c
        |
       add  <-- a
        |
        d
```

Forward:
- c = 2 * 3 = 6
- d = 6 + 2 = 8

Backward:
- dd/dd = 1
- dd/dc = 1 (производная сложения по первому аргументу)
- dd/da = 1 (производная сложения по второму аргументу)
- dc/da = b = 3
- dc/db = a = 2

Итого:
- dd/da = dd/dc * dc/da + dd/da = 1 * 3 + 1 = 4
- dd/db = dd/dc * dc/db = 1 * 2 = 2

Проверка: d = a*b + a = 2*3 + 2 = 8. dd/da = b + 1 = 4. dd/db = a = 2.

## Проверка градиентов (gradient check)

Autograd легко написать с ошибкой в знаке или в транспонировании. Классический способ поймать её — **численная проверка**: сравнить аналитический градиент из `backward()` с приближением через конечные разности.

Идея из определения производной:

$$
f'(x) \approx \frac{f(x + h) - f(x - h)}{2h}
$$

Центральная разность точнее односторонней ($O(h^2)$ против $O(h)$), поэтому используют именно её. $h$ берут маленьким, но не слишком: $h \approx 10^{-4}$ для `float`, $10^{-6}$ для `double` (слишком маленькое $h$ утонет в округлении).

**Алгоритм:**
1. Forward, `backward()` — получаем аналитические градиенты.
2. Для каждого параметра $w$: сохраняем старое значение, делаем $w \leftarrow w + h$, считаем loss $L_+$; делаем $w \leftarrow w - h$, считаем $L_-$; возвращаем $w$.
3. Численный градиент: $g_{\text{num}} = \frac{L_+ - L_-}{2h}$.
4. Сравниваем с аналитическим: относительная ошибка $\frac{|g_{\text{num}} - g_{\text{anal}}|}{\max(|g_{\text{num}}|, |g_{\text{anal}}|, \varepsilon)}$. Если $< 10^{-4}$ — всё хорошо.

```java
/**
 * Численная проверка градиентов для тензорного графа.
 * Вызывать на маленьких тензорах (2–3 элемента): O(numel) forward-проходов.
 *
 * @param lossFn функция, строящая loss из параметров (заново, при каждом вызове!)
 * @param params параметры, по которым проверяем (обычно веса)
 * @return максимальная относительная ошибка по всем элементам
 */
static float gradCheck(java.util.function.Supplier<Tensor> lossFn, Tensor... params) {
    final float h = 1e-4f;
    float maxRelErr = 0f;

    // 1) аналитические градиенты
    Tensor loss = lossFn.get();
    loss.zeroGrad();
    loss.backward();
    float[][] anal = new float[params.length][];
    for (int p = 0; p < params.length; p++) {
        anal[p] = params[p].grad.clone();
    }

    // 2) численные градиенты
    for (int p = 0; p < params.length; p++) {
        Tensor t = params[p];
        for (int i = 0; i < t.data.length; i++) {
            float orig = t.data[i];

            t.data[i] = orig + h;
            float lp = lossFn.get().data[0];

            t.data[i] = orig - h;
            float lm = lossFn.get().data[0];

            t.data[i] = orig;

            float gNum = (lp - lm) / (2 * h);
            float gAna = anal[p][i];
            float denom = Math.max(Math.max(Math.abs(gNum), Math.abs(gAna)), 1e-8f);
            float relErr = Math.abs(gNum - gAna) / denom;
            if (relErr > maxRelErr) maxRelErr = relErr;
        }
    }
    return maxRelErr;
}

// использование:
// float err = gradCheck(
//     () -> x.mul(w).add(b).relu().sum(),
//     x, w, b
// );
// System.out.println("max rel err = " + err);  // должно быть < 1e-3
```

Важно: lossFn должен строить граф заново при каждом вызове (поэтому Supplier, а не готовый Tensor).
Если переиспользовать один и тот же Tensor, граф накопит старые inputs и backward будет считать не то.

Что означают результаты:
- $10^{-4}$ — всё ок
- $10^{-2}$ — возможно ошибка
- 1 или больше — точно ошибка

Проверяйте каждую новую операцию сразу после написания.
Это дешевле, чем потом искать, почему сеть не учится.
