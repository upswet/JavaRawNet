# Тензор

Тензор — это обобщение числа, вектора и матрицы на много измерений.

В ML тензор это многомерный массив.
В памяти он лежит как непрерывный одномерный буфер чисел (float[]).
Метаданные тензора(форма - shape и шаги - stride) позволяют переводить многомерный индекс в плоский и обратно. 

Можно думать так:
- 0D тензор — одно число: 5. Это скаляр.
- 1D тензор — список чисел: [1, 2, 3]. Это вектор.
- 2D тензор — таблица чисел: [[1, 2], [3, 4]]. Это матрица.
- 3D тензор — куб чисел. Например, цветная картинка: высота × ширина × 3 канала RGB.
- 4D тензор — пачка картинок: количество картинок × высота × ширина × каналы.

Тензор суть ключ ко всему так как:
 - позволяет задавать единый вид входа/выхода сети для самых разных слоёв сети (соединить CNN.Conv слой с MLP.Dense-слоем, а его потом с RNN.ElmanRnn слоем? Легко!)
 - резко ускоряет некоторые операции (пример "транспонирование матрицы") превращая их из пересоздания/копирования тела матрицы в просто изменение формы тензора.
 - резко упрощает написание алгоритма обратного распространения ошибки (backward) так как он теперь сводится к построению графа во время прямого прохода сети и его обходу на обратном.

```text
Tensor = strided view (данные + метаданные) + autograd (история вычислений)
```

## Зачем нужны тензоры
Большинство «самодельных» ML-библиотек страдают от двух проблем:
- Копирование данных при каждой операции — медленно и памяти жрёт.
- Ручное вычисление градиентов — формула производной для каждой операции пишется руками, и любая ошибка ломает обучение.

Strided view решает проблему копирования: transpose, reshape, slice — это O(1) операции, которые лишь меняют метаданные, а не данные.

Autograd решает проблему градиентов: каждая операция записывает, как вычислить свою производную, а система автоматически применяет правило цепочки[^1].


## Strided view

В памяти — плоский float[] data. 
Логическая многомерность — это shape, strides, offset. 
Отсюда reshape и transpose работают за O(1): меняем только метаданные.

## Autograd

Каждая операция возвращает тензор, у которого записаны inputs (входные тензоры) и backwardFn (как распределить пришедший градиент по входам). 
backward() обходит граф в обратном топологическом порядке и применяет правило цепочки.

Autograd (автоматическое дифференцирование)— это механизм, который автоматически вычисляет производные сложной функции по её входным параметрам.
